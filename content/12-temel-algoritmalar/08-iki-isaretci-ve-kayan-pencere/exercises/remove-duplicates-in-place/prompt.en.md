Write the function `remove_duplicates(items)` **with fast and slow
pointers**: it removes repeats from a sorted list **in place**; it writes the
unique values at the start of the list and returns the number of unique
elements. Do not build a new list or a set.

- `[1, 1, 2, 3, 3, 3, 4]` → `4`, the first 4 elements of the list are
  `[1, 2, 3, 4]`

**Expected output:**

```
4 [1, 2, 3, 4]
```
