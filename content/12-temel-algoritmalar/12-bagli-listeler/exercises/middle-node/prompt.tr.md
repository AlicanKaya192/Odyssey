`middle(head)` fonksiyonunu **kaplumbağa ve tavşanla** yaz: listenin
ortasındaki düğümün **değerini** döndürsün. Eleman sayısı çiftse iki ortadan
**ikincisini** al. Boş listede `None`.

- `[1, 2, 3, 4, 5]` → `3`, `[1, 2, 3, 4]` → `3`

`slow` bir, `fast` iki adım ilerler; `fast` sona varınca `slow` ortadadır.
Listenin boyunu sayma (`len` yok).

**Beklenen çıktı:**

```
3
3
None
```
