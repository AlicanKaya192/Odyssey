Write the function `find_largest(numbers)` **without using `max()`**: it
takes a non-empty list of numbers and returns the largest.

**What to do:**

1. Start the largest with the **first element** of the list (not `0`).
2. Go through the list in a loop; when you see a bigger number, replace the
   one in mind.
3. Return the result.

The check will also try your function with negative numbers, a
one-element list and a list where all elements are equal.

**Expected output:**

```
17
-3
```
