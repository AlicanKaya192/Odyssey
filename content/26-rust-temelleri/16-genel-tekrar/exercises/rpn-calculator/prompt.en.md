Write `fn eval(expr: &str) -> Result<i32, String>`. The input is reverse Polish notation: `2 3 + 4 *` means `(2 + 3) * 4`. Push a number on the stack; on an operator take two values and push the result. Operators are `+ - *`. If there are too few values on the stack return `too few values`, on a bad piece `bad token: <piece>`, and if a single value is not left at the end `too many values`.
