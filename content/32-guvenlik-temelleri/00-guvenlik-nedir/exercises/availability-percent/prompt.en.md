The availability of a service is the time it was up divided by the
total time, as a percentage.

The function `availability_percent(up_minutes, total_minutes)` should
compute it and round the result to 3 digits (`round(..., 3)`). The starter
code gives a wrong number: run it, find out why and fix it.

**Expected output:**

```
99.903
99.886
100.0
```
