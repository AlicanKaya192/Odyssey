## Document layers

| Layer | Question | Mandatory |
|---|---|---|
| Policy | What and why? | Yes |
| Standard | Which measurable rule? | Yes |
| Procedure | How, step by step? | Yes |
| Guideline | What is recommended? | No |

## Data classes

Public → Internal → Confidential → Restricted. The data's **owner** decides
the class; every class has written rules for storing, sharing and
disposal. An unknown channel is refused.

## Gap analysis

1. List the controls the standard asks for.
2. A status for each: in place / partial / missing.
3. Count an unknown status as "missing".
4. Sort the gaps by risk, give each an owner and a date.

## A good exception

It has an owner, a reason, an end date and a compensating control. When it
expires it is approved again or closed.

## To remember

Compliance is a snapshot; security is whether the controls work every day.
