`layers` is the list of the chances of getting past each layer. If the
layers are independent, the chance of getting past all of them is the
product of these numbers.

Write the function `pass_probability(layers)` and return the result with
`round(..., 4)`. With no layers at all the attack certainly gets through:
`1.0`.

**Expected output:**

```
0.006
0.5
1.0
```
