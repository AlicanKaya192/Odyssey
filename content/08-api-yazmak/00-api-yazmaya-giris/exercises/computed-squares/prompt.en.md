An endpoint is an ordinary Python function: you can compute inside it.

**What to do:** `GET /squares` returns the squares of the numbers 1 to 10 as
a list. Do not type the numbers by hand; compute them with a loop (or a list
comprehension).

**Expected answer:**

```json
[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
```
