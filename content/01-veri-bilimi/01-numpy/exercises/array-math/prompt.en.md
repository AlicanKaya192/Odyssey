You have the unit price and the number sold for four products. You will
compute each product's revenue and its taxed value — **without a loop.**

**What you need to do:**

1. The `prices` and `counts` arrays are ready in the starter code.
2. Compute each product's revenue (`price x count`) into an array called
   `totals`.
3. Add 20% tax to the revenues into an array called `with_tax`.
4. Print: `totals`, then `with_tax` rounded to one decimal place, then the
   total revenue.

**Expected output:**

```
[300 250 400 800]
[360. 300. 480. 960.]
1750
```

**The rule:** no building an empty list and filling it with `append`. You can
do all of it on the arrays in one line each — that is what this section is
about.
