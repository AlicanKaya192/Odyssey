`sort_people(people)` fonksiyonunu yaz: `{"name": ..., "age": ...}`
sözlüklerinden oluşan listeyi **yaşa göre büyükten küçüğe**, yaşı eşit
olanları **ada göre abece sırasıyla** sıralayıp yalnızca adların listesini
döndürsün. Tek anahtar: `(-yaş, ad)`.

**Beklenen çıktı:**

```
['Alan', 'Bob', 'Ada', 'Grace']
```
