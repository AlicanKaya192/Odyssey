Komut satırıyla ilgili okuduğun her yerde karşına çıkacak kelimeler.
Parantez içindekiler İngilizce kaynaklarda göreceğin adlar.

| Kelime | Anlamı |
|---|---|
| Terminal (terminal) | Yazdığını ve gelen cevabı gösteren pencere. |
| Kabuk (shell) | Satırı okuyup çalıştıran program. En yaygını bash. |
| bash | Linux'un ve Git Bash'in kabuğu (*Bourne Again SHell*). |
| İstem (prompt) | Satır başındaki `~ $`: neredesin, komut bekleniyor. |
| Komut (command) | Çalıştırılacak programın adı: `ls`, `pwd`. |
| Seçenek (option, flag) | Komutun davranışını değiştiren, tireli parça: `-a`. |
| Argüman (argument) | Komutun üzerinde çalıştığı şey: dosya, klasör, metin. |
| Çıktı (output) | Komutun ekrana yazdığı cevap. |
| Hata mesajı (error) | Ters giden şeyi anlatan çıktı: `command not found`. |
| Ev klasörü (home) | Sana ait klasör; istemde `~`. Burada `/home/ada`. |
| Gizli dosya (hidden) | Adı nokta ile başlayan dosya; `ls -a` gösterir. |
| Betik (script) | Komutları sırayla yazdığın dosya. |
| Sunucu (server) | Başka işler için çalışan, çoğu zaman ekranı olmayan bilgisayar. |

## Benzer ama farklı

- **Terminal mi, konsol mu, komut istemi mi?** Günlük konuşmada üçü de aynı
  pencere için kullanılır. Windows'taki "Komut İstemi" (cmd) ise ayrı bir
  kabuktur ve komutları farklıdır (`dir`, `cls`).
- **bash mi, zsh mi?** İkisi de kabuk. Bu patikadaki komutlar ikisinde de
  aynı çalışır.
- **Git Bash mi, WSL mi?** Git Bash Windows'ta bash'i ve temel komutları
  çalıştırır; WSL Windows'un içinde gerçek bir Linux açar.
