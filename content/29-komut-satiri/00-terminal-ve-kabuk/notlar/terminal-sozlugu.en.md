Words you will meet everywhere you read about the command line.

| Word | Meaning |
|---|---|
| Terminal | The window that shows what you type and the answer. |
| Shell | The program that reads and runs the line. The most common is bash. |
| bash | The shell of Linux and Git Bash (*Bourne Again SHell*). |
| Prompt | The `~ $` at the start of the line: where you are, a command is expected. |
| Command | The name of the program to run: `ls`, `pwd`. |
| Option (flag) | The part with a dash that changes the behaviour: `-a`. |
| Argument | What the command works on: a file, a folder, some text. |
| Output | The answer the command prints. |
| Error message | Output that explains what went wrong: `command not found`. |
| Home folder | Your own folder; `~` in the prompt. Here `/home/ada`. |
| Hidden file | A file whose name starts with a dot; `ls -a` shows it. |
| Script | A file in which you write commands in order. |
| Server | A computer that works for other jobs, often without a screen. |

## Similar but different

- **Terminal, console or command prompt?** In everyday talk all three mean
  the same window. The "Command Prompt" (cmd) on Windows, however, is a
  separate shell with different commands (`dir`, `cls`).
- **bash or zsh?** Both are shells. The commands in this path work the same
  in both.
- **Git Bash or WSL?** Git Bash runs bash and the basic commands on Windows;
  WSL opens a real Linux inside Windows.
