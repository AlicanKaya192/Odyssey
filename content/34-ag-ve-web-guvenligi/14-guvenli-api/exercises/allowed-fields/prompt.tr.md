`apply_update(profile, body)` profilin **kopyasını** döndürsün; gövdeden
yalnızca `ALLOWED` içindeki alanlar kopyaya yazılsın. Asıl `profile`
değişmesin. Başlangıç kodu gövdenin tamamını yazıyor.

**Beklenen çıktı:**

```
{'name': 'Ada', 'role': 'user', 'bio': 'hi'}
{'name': 'Ada', 'role': 'user'}
```
