The `products` table and the `SORTABLE` dictionary are ready.
`sorted_names(sort)` should return the product names as a list sorted by
the requested column. A column name cannot be a parameter; **map** the
`sort` value to a column with `SORTABLE`, and use `"name"` if it is not in
the list. The starter code writes `sort` into the query as it is.

**Expected output:**

```
['pen', 'cup', 'book', 'bag']
['bag', 'book', 'cup', 'pen']
['bag', 'book', 'cup', 'pen']
```
