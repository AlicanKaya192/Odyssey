Bring back the same two columns, but **change the headings** in the
result:

- `ad` under the heading `urun`,
- `fiyat` under the heading `tutar`.

```
urun      tutar
--------  --------
Klavye    450.00
Monitor   3200.00
...
```

The data stays the same; only the column names in the result change. This
is what you need when you are naming the output of a report, or a result
some program is going to read.
