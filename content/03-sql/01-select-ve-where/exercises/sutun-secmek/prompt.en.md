The `urunler` table has five columns: `id`, `ad`, `kategori`, `fiyat`,
`stok`.

In this exercise we want only the **`ad` and `fiyat`** columns — in that
order.

All eight products will come back; we are not filtering rows here, only
choosing columns.

```
ad        fiyat
--------  --------
Klavye    450.00
Monitor   3200.00
...
```

Press the **Tables** button above if you want to see what is in the table.
