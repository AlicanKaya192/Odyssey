The `products` table has five columns: `id`, `name`, `category`, `price`,
`stock`.

In this exercise we want only the **`name` and `price`** columns — in that
order.

All eight products will come back; we are not filtering rows here, only
choosing columns.

```
name      price 
--------  ------
Keyboard  450.0 
Monitor   3200.0
...
```

Press the **Tables** button above if you want to see what is in the table.
