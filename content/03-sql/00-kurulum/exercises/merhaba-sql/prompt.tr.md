Bu alıştırma bir şey öğretmiyor; **kurulumun çalıştığını** gösteriyor.

Editörde hazır bir satır duruyor. Hiçbir şey değiştirmeden **Çalıştır**'a
bas.

Sonuç panelinde tek sütunlu, tek satırlık bir tablo görmelisin:

```
message  
---------
Hello SQL
```

Bunu gördüysen zincirin tamamı çalışıyor: Odyssey, ODBC sürücüsü ve SQL
Server.

Hata alıyorsan ders sayfasının sonundaki **"Bir şey olmazsa"** başlığına
dön.
