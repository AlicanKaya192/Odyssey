Istanbul'daki tedarikçilerin ürünlerini getir.

Tek sütun: `name`. Alfabetik sırala.

```
name      
----------
Desktop   
Laptop    
Microphone
```

Üçüncü bölümde `IN` yazarken listeyi elle yazıyordun. Burada
**yazmayacaksın**: hangi tedarikçilerin Istanbul'da olduğunu `suppliers`
tablosundan bir alt sorguyla al.

Sebebi aynı: kodları elle yazarsan tedarikçi şehir değiştirdiğinde sorgu
sessizce yanlış olur.

İçerideki sorgu **tek bir sütun** döndürmeli — `IN` karşılaştıracağı
değeri ondan alıyor.
