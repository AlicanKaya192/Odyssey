Bring back the products priced **above the average** of all products.

Columns: `name` and `price`. Sort from expensive to cheap.

```
name       price  
---------  -------
Laptop     24500.0
Desktop    18900.0
Projector  7400.0 
```

**Do not type the average in by hand.** Work it out today and write it as
a constant, and the query is wrong tomorrow when the data changes.

You can write a `SELECT` inside parentheses; as long as its result is a
single number it is used like a constant.
