Bring back the `ad` and `kategori` of products in the `Ekran` **or**
`Yazilim` category, in alphabetical order.

```
ad           kategori
-----------  --------
Antivirus    Yazilim
Monitor      Ekran
...
```

You could write this with `OR` and get the same result. But this exercise
asks for **`IN`**: with two values the difference is small, with ten an
`OR` chain becomes unreadable.

The result should be four rows.
