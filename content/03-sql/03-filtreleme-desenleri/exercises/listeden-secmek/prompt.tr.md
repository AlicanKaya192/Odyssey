`Display` **ya da** `Software` kategorisindeki ürünlerin `name` ve `category`
bilgisini alfabetik sırada getir.

```
name       category
---------  --------
Antivirus  Software
Monitor    Display 
...
```

Bunu `OR` ile de yazabilirsin ve aynı sonucu alırsın. Ama bu alıştırma
**`IN`** istiyor: iki değer için fark küçük, on değer için `OR` zinciri
okunmaz hâle geliyor.

Sonuç dört satır olmalı.
