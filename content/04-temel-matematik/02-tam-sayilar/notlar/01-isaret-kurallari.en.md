## The number line

$$
\dots < -3 < -2 < -1 < 0 < 1 < 2 < 3 < \dots
$$

The number further right is larger. $-5 < -2$, because $-5$ is further left.

## Opposites and absolute value

| Idea | Definition | Example |
|---|---|---|
| Opposite | $a + (-a) = 0$ | the opposite of $7$ is $-7$ |
| Double minus | $-(-a) = a$ | $-(-5) = 5$ |
| Absolute value | distance from zero, always $\ge 0$ | $\lvert -9 \rvert = 9$ |
| Distance between two numbers | $|a - b|$ | $\lvert -3 - 5 \rvert = 8$ |

## Addition

| Case | Do | Example |
|---|---|---|
| Same sign | add the absolute values, keep the sign | $-4 + (-6) = -10$ |
| Different signs | subtract the smaller from the larger, take the larger's sign | $-9 + 4 = -5$ |

## Subtraction

$$
a - b = a + (-b)
$$

$5 - (-4) = 5 + 4 = 9$. Subtracting a negative is adding its positive.

## Multiplication and division

| | $+$ | $-$ |
|---|---|---|
| $+$ | $+$ | $-$ |
| $-$ | $-$ | $+$ |

With many factors, count the minuses: an even number of minuses → $+$, odd → $-$.

## Powers

| Expression | Value | Why |
|---|---|---|
| $(-2)^2$ | $4$ | the base is $-2$ |
| $-2^2$ | $-4$ | the exponent belongs only to $2$ |
| $(-2)^3$ | $-8$ | odd power, negative |
| $(-1)^n$ | $1$ if $n$ is even, $-1$ if odd | |

## Practical tips

- Turn every subtraction into addition, then use only the two addition rules.
- In multiplication, multiply the absolute values first and set the sign last by counting minuses.
- "Two minuses make a plus" is only for multiplication and division. $-3 + (-4) = -7$.
- Work out the inside of an absolute value first: $|3 - 8| = 5$.
- Put a negative number in brackets inside an operation: $3 \cdot (-2)$, not $3 \cdot -2$.
