A worked example for each method in the lesson. Try the question yourself first, then read the solution.

## 1. Evaluating

**Question:** If $f(x) = 3x^2 - x$, what are $f(-1)$ and $f(2)$?

$f(-1) = 3 + 1 = 4$; $f(2) = 12 - 2 = 10$.

## 2. Putting in an expression

**Question:** If $f(x) = x^2 + 1$, what is $f(t - 2)$?

$(t - 2)^2 + 1 = t^2 - 4t + 5$.

## 3. A function?

**Question:** Is $\{(1, 3), (2, 5), (1, 4)\}$ a function?

No: the input $1$ has two outputs ($3$ and $4$).

## 4. The domain

**Question:** What is the domain of $f(x) = \dfrac{\sqrt{x + 2}}{x - 1}$?

$x + 2 \ge 0 \Rightarrow x \ge -2$, and $x \neq 1$.

## 5. Composition

**Question:** If $f(x) = x - 4$ and $g(x) = 3x$, what are $(f \circ g)(2)$ and $(g \circ f)(2)$?

$f(g(2)) = f(6) = 2$; $g(f(2)) = g(-2) = -6$.

## 6. The inverse function

**Question:** What is the inverse of $f(x) = \dfrac{x + 5}{2}$?

$y = \dfrac{x + 5}{2} \Rightarrow 2y - 5 = x$: $f^{-1}(x) = 2x - 5$.

## 7. Reading from a graph

**Question:** A line passes through $(0, 2)$ and $(3, 8)$. What is $f(5)$?

It rises by $\frac{8 - 2}{3} = 2$ per unit of $x$: $f(x) = 2x + 2$, $f(5) = 12$.

## 8. ReLU

**Question:** For $\text{ReLU}(x) = \max(0, x)$, what are $\text{ReLU}(-3)$, $\text{ReLU}(0)$ and $\text{ReLU}(2.5)$?

$0$, $0$ and $2.5$.
