All the formulas of the Foundational Mathematics module on one page. Come back here when you get stuck on a question; the details are in each section's reference note.

## Numbers, powers and roots

| Rule | Formula |
|---|---|
| order of operations | brackets → powers → multiplication, division → addition, subtraction |
| adding fractions | $\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$ |
| powers | $a^m a^n = a^{m+n}$, $(a^m)^n = a^{mn}$, $a^0 = 1$, $a^{-n} = \frac{1}{a^n}$ |
| roots | $\sqrt{ab} = \sqrt{a}\sqrt{b}$, $a^{1/n} = \sqrt[n]{a}$ |
| percentage change | $\times (1 + r)$ increase, $\times (1 - r)$ decrease |

## Algebra

| Topic | Formula |
|---|---|
| identities | $(a \pm b)^2 = a^2 \pm 2ab + b^2$, $a^2 - b^2 = (a - b)(a + b)$ |
| quadratics | $x = \frac{-b \pm \sqrt{\Delta}}{2a}$, $\Delta = b^2 - 4ac$ |
| vertex | $x = -\frac{b}{2a}$ |
| inequalities | multiplying by a negative flips the sign |
| absolute value | $\lvert x \rvert < a \iff -a < x < a$ |

## Functions

| Topic | Formula |
|---|---|
| line | $m = \frac{y_2 - y_1}{x_2 - x_1}$, $y = mx + b$; perpendicular: $m_1 m_2 = -1$ |
| distance | $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ |
| polynomial | remainder theorem: the remainder on division by $(x - a)$ is $P(a)$ |
| exponential | $a \cdot b^x$; $b > 1$ growth, $0 < b < 1$ decay |
| logarithm | $\log_b x = y \iff b^y = x$; $\log(ab) = \log a + \log b$; $\log a^n = n \log a$ |

## Sequences and Σ

| Topic | Formula |
|---|---|
| arithmetic | $a_n = a_1 + (n - 1)d$, $S_n = \frac{n(a_1 + a_n)}{2}$ |
| geometric | $a_n = a_1 r^{n-1}$, $S_n = a_1 \frac{1 - r^n}{1 - r}$ |
| infinite geometric | $\frac{a_1}{1 - r}$, $-1 < r < 1$ |
| Gauss | $\sum_{i=1}^{n} i = \frac{n(n + 1)}{2}$ |

## Geometry and trigonometry

| Topic | Formula |
|---|---|
| Pythagoras | $a^2 + b^2 = c^2$ |
| area | triangle $\frac{1}{2} t h$, disc $\pi r^2$; circumference $2\pi r$ |
| ratios | $\sin = \frac{\text{opposite}}{\text{hypotenuse}}$, $\cos = \frac{\text{adjacent}}{\text{hypotenuse}}$, $\tan = \frac{\sin}{\cos}$ |
| identity | $\sin^2 + \cos^2 = 1$ |
| radians | $180° = \pi$ |

## Counting, probability, statistics

| Topic | Formula |
|---|---|
| permutation | $\frac{n!}{(n - k)!}$ |
| combination | $\binom{n}{k} = \frac{n!}{k!(n - k)!}$ |
| complement | $P(A') = 1 - P(A)$ |
| union | $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ |
| independent | $P(A \cap B) = P(A) P(B)$ |
| conditional | $P(B \mid A) = \frac{P(A \cap B)}{P(A)}$ |
| mean | $\bar{x} = \frac{1}{n} \sum x_i$ |
| variance | $\frac{1}{n} \sum (x_i - \bar{x})^2$; $n - 1$ for a sample |
| z-score | $\frac{x - \bar{x}}{\sigma}$ |
