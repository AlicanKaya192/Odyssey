MAT 1'in bütün formülleri tek sayfada. Bir soruda takıldığında buraya dön; ayrıntısı ilgili bölümün başvuru notunda.

## Sayılar, üs ve kök

| Kural | Formül |
|---|---|
| işlem önceliği | parantez → üs → çarpma, bölme → toplama, çıkarma |
| kesir toplama | $\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$ |
| üs | $a^m a^n = a^{m+n}$, $(a^m)^n = a^{mn}$, $a^0 = 1$, $a^{-n} = \frac{1}{a^n}$ |
| kök | $\sqrt{ab} = \sqrt{a}\sqrt{b}$, $a^{1/n} = \sqrt[n]{a}$ |
| yüzde değişim | $\times (1 + r)$ artış, $\times (1 - r)$ azalış |

## Cebir

| Konu | Formül |
|---|---|
| özdeşlikler | $(a \pm b)^2 = a^2 \pm 2ab + b^2$, $a^2 - b^2 = (a - b)(a + b)$ |
| ikinci derece | $x = \frac{-b \pm \sqrt{\Delta}}{2a}$, $\Delta = b^2 - 4ac$ |
| tepe noktası | $x = -\frac{b}{2a}$ |
| eşitsizlik | negatifle çarpınca yön döner |
| mutlak değer | $\lvert x \rvert < a \iff -a < x < a$ |

## Fonksiyonlar

| Konu | Formül |
|---|---|
| doğru | $m = \frac{y_2 - y_1}{x_2 - x_1}$, $y = mx + b$; dik: $m_1 m_2 = -1$ |
| uzaklık | $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ |
| polinom | kalan teoremi: $(x - a)$'ya bölümden kalan $P(a)$ |
| üstel | $a \cdot b^x$; $b > 1$ büyüme, $0 < b < 1$ azalma |
| logaritma | $\log_b x = y \iff b^y = x$; $\log(ab) = \log a + \log b$; $\log a^n = n \log a$ |

## Diziler ve Σ

| Konu | Formül |
|---|---|
| aritmetik | $a_n = a_1 + (n - 1)d$, $S_n = \frac{n(a_1 + a_n)}{2}$ |
| geometrik | $a_n = a_1 r^{n-1}$, $S_n = a_1 \frac{1 - r^n}{1 - r}$ |
| sonsuz geometrik | $\frac{a_1}{1 - r}$, $-1 < r < 1$ |
| Gauss | $\sum_{i=1}^{n} i = \frac{n(n + 1)}{2}$ |

## Geometri ve trigonometri

| Konu | Formül |
|---|---|
| Pisagor | $a^2 + b^2 = c^2$ |
| alan | üçgen $\frac{1}{2} t h$, daire $\pi r^2$; çevre $2\pi r$ |
| oranlar | $\sin = \frac{\text{karşı}}{\text{hipotenüs}}$, $\cos = \frac{\text{komşu}}{\text{hipotenüs}}$, $\tan = \frac{\sin}{\cos}$ |
| özdeşlik | $\sin^2 + \cos^2 = 1$ |
| radyan | $180° = \pi$ |

## Sayma, olasılık, istatistik

| Konu | Formül |
|---|---|
| permütasyon | $\frac{n!}{(n - k)!}$ |
| kombinasyon | $\binom{n}{k} = \frac{n!}{k!(n - k)!}$ |
| tümleyen | $P(A') = 1 - P(A)$ |
| birleşim | $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ |
| bağımsız | $P(A \cap B) = P(A) P(B)$ |
| koşullu | $P(B \mid A) = \frac{P(A \cap B)}{P(A)}$ |
| ortalama | $\bar{x} = \frac{1}{n} \sum x_i$ |
| varyans | $\frac{1}{n} \sum (x_i - \bar{x})^2$; örneklemde $n - 1$ |
| z puanı | $\frac{x - \bar{x}}{\sigma}$ |
