You have finished the Foundational Mathematics module. There are two paths from here, and they complement each other.

## The Mathematics of AI

Every branch of the Foundational Mathematics module climbs one level in the Advanced Mathematics module:

| In the Foundational Mathematics module | In the Advanced Mathematics module |
|---|---|
| coordinates, distance, trigonometry | vectors, dot product, cosine similarity |
| systems of equations | matrices, Gaussian elimination, rank |
| functions, slope | limits, derivatives, the chain rule |
| polynomials | Taylor approximation |
| area | integrals |
| exponentials and logarithms | gradient descent, log loss, entropy |
| probability | conditional probability, Bayes, distributions |
| statistics | sampling, confidence intervals, the mathematics of regression |

The first section of the Advanced Mathematics module is Vectors; keeping The Coordinate Plane and
Lines and Trigonometry fresh is enough.

## The machine learning path

The Machine Learning path brings mathematics and code together. Behind every
formula you see there is a piece of this module: linear regression is a
line, logistic regression a sigmoid, accuracy a ratio, scaling a z-score.

## Suggestions for review

- If you got stuck in a section, go back to its **reference note** first,
  then to its **worked examples**.
- Every question you get wrong in the review quiz points to a section; the
  table in the Quick Reference shows where to go.
- The most common mistakes (squares, roots and logarithms not distributing
  over sums, percentages not adding up, signs) are in the table in the
  Overall Review.
