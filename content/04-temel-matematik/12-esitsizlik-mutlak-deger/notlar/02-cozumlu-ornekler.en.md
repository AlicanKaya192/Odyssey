A worked example for each method in the lesson. Try the question yourself first, then read the solution.

## 1. A simple inequality

**Question:** Solve $4x - 7 < 13$.

$4x < 20$, $x < 5$. Interval: $(-\infty, 5)$.

## 2. Flipping

**Question:** Solve $2 - 5x \le 17$.

$-5x \le 15$; dividing by $-5$ flips it: $x \ge -3$.

## 3. The unknown on both sides

**Question:** Solve $3x + 2 > 5x - 8$.

$10 > 2x$, so $x < 5$.

## 4. A double inequality

**Question:** Solve $-4 < 2x + 2 \le 10$.

$-6 < 2x \le 8$, $-3 < x \le 4$. Interval $(-3, 4]$.

## 5. An absolute-value equation

**Question:** Solve $|3x + 1| = 8$.

$3x + 1 = 8 \Rightarrow x = \frac{7}{3}$; $3x + 1 = -8 \Rightarrow x = -3$.

## 6. Inside

**Question:** Solve $|x + 3| < 2$.

$-2 < x + 3 < 2$, $-5 < x < -1$.

## 7. Outside

**Question:** Solve $|2x - 4| \ge 6$.

$2x - 4 \ge 6 \Rightarrow x \ge 5$; $2x - 4 \le -6 \Rightarrow x \le -1$.
Solution: $x \le -1$ or $x \ge 5$.

## 8. From an interval to absolute value

**Question:** Write the interval $-2 \le x \le 8$ with absolute value.

Centre $\frac{-2 + 8}{2} = 3$, radius $\frac{8 - (-2)}{2} = 5$:
$|x - 3| \le 5$.
