Dersteki yöntemlerin her biri için adım adım çözülmüş bir örnek. Önce soruyu kendin çözmeye çalış, sonra çözümü oku.

## 1. Basit eşitsizlik

**Soru:** $4x - 7 < 13$'ü çöz.

$4x < 20$, $x < 5$. Aralık: $(-\infty, 5)$.

## 2. Yön değişimi

**Soru:** $2 - 5x \le 17$'yi çöz.

$-5x \le 15$; $-5$'e bölünce yön döner: $x \ge -3$.

## 3. Bilinmeyen iki tarafta

**Soru:** $3x + 2 > 5x - 8$'i çöz.

$10 > 2x$, yani $x < 5$.

## 4. Çift eşitsizlik

**Soru:** $-4 < 2x + 2 \le 10$'u çöz.

$-6 < 2x \le 8$, $-3 < x \le 4$. Aralık $(-3, 4]$.

## 5. Mutlak değerli denklem

**Soru:** $|3x + 1| = 8$'i çöz.

$3x + 1 = 8 \Rightarrow x = \frac{7}{3}$; $3x + 1 = -8 \Rightarrow x = -3$.

## 6. İçeride

**Soru:** $|x + 3| < 2$'yi çöz.

$-2 < x + 3 < 2$, $-5 < x < -1$.

## 7. Dışarıda

**Soru:** $|2x - 4| \ge 6$'yı çöz.

$2x - 4 \ge 6 \Rightarrow x \ge 5$; $2x - 4 \le -6 \Rightarrow x \le -1$.
Çözüm: $x \le -1$ ya da $x \ge 5$.

## 8. Aralıktan mutlak değere

**Soru:** $-2 \le x \le 8$ aralığını mutlak değerle yaz.

Merkez $\frac{-2 + 8}{2} = 3$, yarıçap $\frac{8 - (-2)}{2} = 5$:
$|x - 3| \le 5$.
