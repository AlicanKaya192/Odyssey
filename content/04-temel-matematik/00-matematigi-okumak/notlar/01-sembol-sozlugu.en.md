## Number sets

| Symbol | Name | Example |
|---|---|---|
| $\mathbb{N}$ | Natural numbers | $0, 1, 2, \dots$ |
| $\mathbb{Z}$ | Integers | $\dots, -1, 0, 1, \dots$ |
| $\mathbb{Q}$ | Rational numbers | $\tfrac{3}{4}$, $-0.5$ |
| $\mathbb{R}$ | Real numbers | $\sqrt{2}$, $\pi$, and all of the above |

$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$. Real numbers that cannot be written as a fraction are **irrational**.

## Operations

| Written | Read as |
|---|---|
| $a + b$, $a - b$ | plus, minus |
| $a \cdot b$, $a \times b$, $ab$ | times |
| $a / b$, $\frac{a}{b}$, $a \div b$ | divided by |
| $a^n$ | $a$ to the power $n$ |
| $\sqrt{a}$ | square root of $a$ |
| $\lvert a \rvert$ | absolute value of $a$ |

## Relations

| Symbol | Read as |
|---|---|
| $=$, $\ne$ | equals, is not equal to |
| $<$, $>$ | less than, greater than (the mouth faces the larger) |
| $\le$, $\ge$ | less than or equal, greater than or equal |
| $\approx$ | approximately equal |
| $\Rightarrow$, $\iff$ | implies; if and only if |
| $\in$, $\notin$, $\subset$ | is an element of, is not an element of, is a subset of |

## Terms

| Term | Example ($3x^2 - 5x + 7$) |
|---|---|
| Term | $3x^2$, $-5x$, $7$ |
| Coefficient (with its sign) | $3$, $-5$ |
| Variable | $x$ |
| Exponent | $2$ |
| Constant term | $7$ |

Expression: no equals sign. Equation: two expressions equal. Inequality:
$<, >, \le, \ge$. Identity: true for every value.

## Scripts

- $x^2$: exponent, an operation ($x \cdot x$). $x_2$: subscript, a name (the second $x$).
- $x_1, x_2, \dots, x_n$: $n$ elements.
- $\sum_{i=1}^{n} x_i = x_1 + x_2 + \cdots + x_n$.
- $f(x)$: the value the rule $f$ gives for $x$ (not a product).
- $\hat{y}$: a prediction ("$y$ hat").

## Greek letters (the most common)

$\alpha$ alpha, $\beta$ beta, $\gamma$ gamma, $\delta/\Delta$ delta,
$\varepsilon$ epsilon, $\theta$ theta, $\lambda$ lambda, $\mu$ mu, $\pi$ pi,
$\sigma/\Sigma$ sigma, $\varphi$ phi.

## Practical tips

- When substituting, put a negative number in brackets: $(-3)^2 = 9$.
- In $2x$ with $x = 5$ the result is $10$; a number and letter side by side are multiplied.
- The top and bottom of a fraction bar are calculated separately.
- To understand a formula, read it aloud.
