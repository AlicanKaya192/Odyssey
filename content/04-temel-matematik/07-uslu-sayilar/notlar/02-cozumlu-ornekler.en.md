A worked example for each method in the lesson. Try the question yourself first, then read the solution.

## 1. Using the rules together

**Question:** What is $\dfrac{3^4 \cdot 3^{-2}}{3^5}$?

Numerator: $3^{4 + (-2)} = 3^2$. Division: $3^{2 - 5} = 3^{-3} = \dfrac{1}{27}$.

## 2. A power of a power

**Question:** What is $(2^3)^4 \div 2^{10}$?

$(2^3)^4 = 2^{12}$; $2^{12} \div 2^{10} = 2^2 = 4$.

## 3. A power of a product

**Question:** Simplify $(3x^2)^3$.

Spread over each factor: $3^3 \cdot (x^2)^3 = 27x^6$.

## 4. A negative exponent and a fraction

**Question:** What is $\left(\dfrac{3}{4}\right)^{-2}$?

Flip the fraction, then square: $\left(\dfrac{4}{3}\right)^2 = \dfrac{16}{9}$.

## 5. Converting to the same base

**Question:** What is $\dfrac{9^3}{27^2}$?

$9 = 3^2$, $27 = 3^3$: $\dfrac{3^6}{3^6} = 3^0 = 1$.

## 6. An exponential equation

**Question:** If $5^{x + 1} = 125$, what is $x$?

$125 = 5^3$, so $x + 1 = 3$, $x = 2$.

## 7. Scientific notation

**Question:** What is $\dfrac{8 \times 10^5}{4 \times 10^{-2}}$?

Coefficients: $8 \div 4 = 2$. Exponents: $5 - (-2) = 7$. The result is
$2 \times 10^7$, that is, $20$ million.

## 8. Tidying a sum

**Question:** $2^{10} + 2^{10}$ is which power of $2$?

We are adding the same thing twice: $2 \cdot 2^{10} = 2^{11}$. (Not
$2^{20}$!)
