## Definition

| Expression | Meaning |
|---|---|
| $\sqrt{a}$ | the non-negative number whose square is $a$ ($a \ge 0$) |
| $\sqrt[3]{a}$ | the number whose cube is $a$ (exists for negative $a$ too) |
| $\sqrt[n]{a}$ | the number whose $n$th power is $a$ |
| $x^2 = a$ | $x = \pm\sqrt{a}$ (two solutions) |

## Rules

| Rule | Formula |
|---|---|
| Multiplication | $\sqrt{ab} = \sqrt{a}\,\sqrt{b}$ |
| Division | $\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}$ |
| Square and root | $(\sqrt{a})^2 = a$, $\sqrt{x^2} = |x|$ |
| Fractional exponent | $a^{1/n} = \sqrt[n]{a}$, $a^{m/n} = (\sqrt[n]{a})^m$ |
| **Addition** | $\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}$ |

## Simplifying

1. Find the largest perfect-square factor of the number under the root.
2. $\sqrt{k^2 \cdot m} = k\sqrt{m}$.
3. Add like roots: $p\sqrt{m} + q\sqrt{m} = (p + q)\sqrt{m}$.

| Root | Simplest form |
|---|---|
| $\sqrt{8}$ | $2\sqrt{2}$ |
| $\sqrt{12}$ | $2\sqrt{3}$ |
| $\sqrt{18}$ | $3\sqrt{2}$ |
| $\sqrt{50}$ | $5\sqrt{2}$ |
| $\sqrt{72}$ | $6\sqrt{2}$ |
| $\sqrt{200}$ | $10\sqrt{2}$ |

## Clearing a root from the denominator

$$
\frac{a}{\sqrt{b}} = \frac{a\sqrt{b}}{b}
$$

## Values worth remembering

$$
\sqrt{2} \approx 1.414, \qquad \sqrt{3} \approx 1.732, \qquad \sqrt{5} \approx 2.236, \qquad \sqrt{10} \approx 3.162
$$

## Practical tips

- To estimate a root, trap it between two perfect squares: $196 < 200 < 225$, so $14 < \sqrt{200} < 15$.
- With a fractional exponent, take the root first, then the power: $27^{2/3} = 3^2 = 9$.
- The $\sqrt{\;}$ sign gives one value; the $\pm$ comes when solving an equation.
- In multiplication, coefficients and roots multiply separately: $2\sqrt{3} \cdot 5\sqrt{2} = 10\sqrt{6}$.
