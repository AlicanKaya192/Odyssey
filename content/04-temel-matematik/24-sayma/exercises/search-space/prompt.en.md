A grid search is run for a model: the learning rate takes $5$ values, the tree depth $4$ values, the number of trees $3$ values, and each setting is trained with $5$-fold cross-validation. A choice among $10$ features is also to be made.

1. How many trainings does the grid search do in total?
2. How many subsets contain exactly $3$ of the $10$ features?
3. How many subsets contain at least one feature?
