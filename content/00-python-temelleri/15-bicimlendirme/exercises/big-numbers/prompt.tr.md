Büyük sayılar ayırıcısız okunmuyor. Üç satırı da okunur hâle
getireceksin.

Elindeki veri:

```python
population = 84680000
budget = 1234567.891
```

**Yapman gerekenler:**

1. Nüfusu binlik ayırıcıyla yaz.
2. Bütçeyi binlik ayırıcı **ve** iki ondalık basamakla yaz.
3. Bütçeyi bir de ondalıksız, yine ayırıcıyla yaz (yuvarlanacak).

**Beklenen çıktı:**

```
Population: 84,680,000
Budget: 1,234,567.89
Rounded: 1,234,568
```

> Ayırıcı `,`, basamak `.2f`. İkisi birlikte `,.2f` diye yazılıyor.
