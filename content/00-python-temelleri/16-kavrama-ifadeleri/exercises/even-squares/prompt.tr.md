Kavramanın iki yüzünü aynı veride göreceksin: **süzgeç** eleman eler,
**koşullu değer** her elemana bir şey yazar.

Elindeki veri:

```python
numbers = [1, 2, 3, 4, 5, 6]
```

**Yapman gerekenler — ikisini de kavrama ile yaz:**

1. `squares` — yalnızca **çift** sayıların kareleri.
2. `labels` — her sayı için `"even"` ya da `"odd"`.

Sonra ikisini sırayla yazdır.

**Beklenen çıktı:**

```
[4, 16, 36]
['odd', 'even', 'odd', 'even', 'odd', 'even']
```

> Süzgeç sonda (`... if n % 2 == 0`), koşullu değer başta
> (`"even" if ... else "odd" for ...`).
