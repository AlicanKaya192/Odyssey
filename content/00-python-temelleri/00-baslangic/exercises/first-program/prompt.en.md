Print two lines to the screen.

The first line is a **string**:

```
Hello, Odyssey
```

The second line is a **number**:

```
2026
```

So the expected output is exactly this:

```
Hello, Odyssey
2026
```

> Text goes in quotes; numbers do not. If you write `Hello` without quotes, Python takes it for a variable name and raises an error.
