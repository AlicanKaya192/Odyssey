Ekrana iki satır yazdır.

Birinci satır bir **metin** olacak:

```
Hello, Odyssey
```

İkinci satır bir **sayı** olacak:

```
2026
```

Yani beklenen çıktı tam olarak şu:

```
Hello, Odyssey
2026
```

> Metinler tırnak içine alınır, sayılar alınmaz. Tırnaksız `Hello` yazarsan Python onu bir değişken adı sanar ve hata verir.
