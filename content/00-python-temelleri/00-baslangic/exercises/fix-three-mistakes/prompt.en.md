The starting code has three lines and **each of them has a mistake**. Run
the code, read the error message, fix the line and run it again. When all
of them are fixed, the output should be:

```
Hello
Total: 8
Done
```

Error messages look scary at first, but they always tell you two things:
**which line** and **what kind** of problem. Python shows the errors one
at a time; fix one and it moves on to the next.

> Watch out: on the second line, do not type the total (`8`) yourself;
> keep the `5 + 3` calculation and fix only the mistake.
