When you leave numbers out of quotes, Python treats them as real **numbers** and
computes with them.

Print three calculations. Do not work out the answers yourself and type them —
**write the calculation** and let Python find the result.

| What to print | Result |
|---|---|
| 12 times 12 | 144 |
| 100 minus 58 | 42 |
| Seconds in a day: 60 times 60 times 24 | 86400 |

Expected output:

```
144
42
86400
```

> Write `print("12 * 12")` and you will see `12 * 12` on screen, not 144. Quotes
> tell Python "do not compute this, print it as it is".
