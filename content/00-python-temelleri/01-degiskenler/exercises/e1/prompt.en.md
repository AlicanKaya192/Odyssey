Define two variables:

- Create a variable called `language` and put `Python` in it.
- Create a variable called `year` and put the number `1991` in it.

Then print the following as a single line:

```
Python 1991
```

There must be **exactly one space** between the language name and the year.

> Hint: if you use a comma inside `print()`, Python adds the space for you.
