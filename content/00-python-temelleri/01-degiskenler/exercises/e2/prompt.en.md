Write a function called `yas_hesapla`.

The function should:

- Take an age as **text** (for example `"25"`).
- Convert that text into a whole number.
- Add 5 to it and **return** the result with `return`.

After writing the function, call it with `"25"` and print the result. The output should be:

```
30
```

> Note: the function must not print the result itself — it must `return` it. You do the printing outside the function.
