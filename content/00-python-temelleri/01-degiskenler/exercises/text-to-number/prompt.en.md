You are given two variables:

- `price_text` — a **string** containing `"45"`
- `count` — a **number**, `3`

What you need to do:

1. Convert the `price_text` string into a whole number.
2. Multiply it by `count` and store the result in a variable called `total`.
3. Print the result using an f-string.

Expected output:

```
Total: 135
```

> Why does it need converting? Multiplying a string by a number repeats it: `"45" * 3` gives `"454545"`, not `135`.
