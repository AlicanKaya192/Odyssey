The most comfortable way to place variables inside text is an **f-string**. You
put an `f` before the quote and write the variable's name inside curly brackets.

Create three variables:

| Variable | Value |
|---|---|
| `name` | `Ada` |
| `language` | `Python` |
| `year` | `2026` |

Then print this sentence using **a single f-string**:

```
Ada is learning Python in 2026.
```

> Do not forget the full stop at the end.
