Değişkenleri bir metnin içine yerleştirmenin en rahat yolu **f-string**. Tırnağın
önüne `f` koyar, değişkenin adını süslü parantez içine yazarsın.

Üç değişken oluştur:

| Değişken | Değer |
|---|---|
| `name` | `Ada` |
| `language` | `Python` |
| `year` | `2026` |

Sonra **tek bir f-string** ile şu cümleyi yazdır:

```
Ada is learning Python in 2026.
```

> Sondaki noktayı unutma.
