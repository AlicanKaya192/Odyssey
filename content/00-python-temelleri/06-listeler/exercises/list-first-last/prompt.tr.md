Bir dil listesi verilmiş:

```python
languages = ["Python", "Java", "Go", "Rust"]
```

Üç değişken oluştur:

| Değişken | Ne olacak |
|---|---|
| `first` | listenin **ilk** elemanı |
| `last` | listenin **son** elemanı |
| `total` | listede kaç eleman olduğu |

Üçünü alt alta yazdır. Beklenen çıktı:

```
Python
Rust
4
```

> Değerleri elle yazma; listeden **sıra numarasıyla** al. Son eleman için
> negatif numara en kısa yol.
