A list of languages is given:

```python
languages = ["Python", "Java", "Go", "Rust"]
```

Create three variables:

| Variable | What it holds |
|---|---|
| `first` | the **first** item of the list |
| `last` | the **last** item of the list |
| `total` | how many items the list has |

Print all three, one under the other. Expected output:

```
Python
Rust
4
```

> Do not type the values by hand; take them from the list **by index**. For the
> last item, a negative index is the shortest way.
