A list of exam results is given:

```python
scores = [42, 78, 15, 91, 50, 63]
```

Count how many results are **greater than** 50. Keep the count in a variable
called `count` and print it.

Expected output:

```
3
```

In this exercise you put a condition inside a loop: walk over the list, check
each item, and add one to the counter when it satisfies the condition.

> Note: 50 is in the list but must not be counted, because the question asks for
> "greater than 50". This is exactly where `>` and `>=` differ.
