Using a loop, print the first five rows of the 7 times table.

Expected output:

```
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35
```

Loop from 1 to 5 with `range()` and build each line with an f-string.

> `range(1, 6)` produces 1, 2, 3, 4, 5 — the end number is **not included**.
> Write `range(1, 5)` and the last row will be missing.
