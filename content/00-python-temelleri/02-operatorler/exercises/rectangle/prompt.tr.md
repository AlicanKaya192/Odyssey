Bir dikdörtgenin kenarları verilmiş:

```python
width = 8
height = 5
```

İki hesap yap:

- `area` — **alan**: iki kenarın çarpımı.
- `perimeter` — **çevre**: kenarların toplamının iki katı.

İkisini alt alta yazdır. Beklenen çıktı:

```
40
26
```

> Çevre hesabında parantez gerekiyor: `2 * (width + height)`. Parantezsiz
> yazarsan Python önce çarpar sonra toplar ve yanlış sonuç çıkar.
