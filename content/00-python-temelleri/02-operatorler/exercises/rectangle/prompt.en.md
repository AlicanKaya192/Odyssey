A rectangle's sides are given:

```python
width = 8
height = 5
```

Do two calculations:

- `area` — the **area**: the two sides multiplied.
- `perimeter` — the **perimeter**: twice the sum of the sides.

Print them one under the other. Expected output:

```
40
26
```

> The perimeter needs brackets: `2 * (width + height)`. Without them Python
> multiplies first and then adds, which gives the wrong answer.
