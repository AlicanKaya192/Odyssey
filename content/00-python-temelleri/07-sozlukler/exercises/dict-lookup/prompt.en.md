A dictionary of capital cities is given:

```python
capitals = {"Turkey": "Ankara", "France": "Paris", "Japan": "Tokyo"}
```

Create three variables:

| Variable | What it holds |
|---|---|
| `turkey` | the capital of Turkey |
| `japan` | the capital of Japan |
| `total` | how many pairs the dictionary has |

Print all three, one under the other. Expected output:

```
Ankara
Tokyo
3
```

> Do not type the values; take them from the dictionary **by key**. Inside the
> square brackets goes a key, not an index: `capitals["Turkey"]`.
