Başkentleri tutan bir sözlük verilmiş:

```python
capitals = {"Turkey": "Ankara", "France": "Paris", "Japan": "Tokyo"}
```

Üç değişken oluştur:

| Değişken | Ne olacak |
|---|---|
| `turkey` | Türkiye'nin başkenti |
| `japan` | Japonya'nın başkenti |
| `total` | sözlükte kaç çift olduğu |

Üçünü alt alta yazdır. Beklenen çıktı:

```
Ankara
Tokyo
3
```

> Değerleri elle yazma; sözlükten **anahtarla** al. Köşeli parantezin içine
> sıra numarası değil anahtar yazılır: `capitals["Turkey"]`.
