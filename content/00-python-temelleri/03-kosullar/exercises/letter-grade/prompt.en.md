The variable `score` holds an exam score. Work out the letter grade for it.

The scale:

| Score | Letter |
|---|---|
| 90 and above | `A` |
| 80 – 89 | `B` |
| 70 – 79 | `C` |
| below 70 | `F` |

- Store the result in a variable called `grade`.
- Then print `grade` to the screen.

Since `score = 85`, the expected output is:

```
B
```

> Watch the order of your conditions. If you do not start from the highest threshold, a high score will match a lower one first and get the wrong letter.
