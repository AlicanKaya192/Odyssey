Three numbers are given:

```python
a = 14
b = 27
c = 9
```

Find the largest, put it into a variable called `largest`, then print it.
Expected output:

```
27
```

Do not use the built-in `max()` — write the comparison yourself.

> One approach: **assume** `a` is the largest, then compare it with `b` and `c`
> in turn. Whenever you see something bigger, update `largest`. This method works
> for three numbers and for thirty.
