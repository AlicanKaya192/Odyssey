The way to tell whether a number is even: when divided by two, is the remainder
zero?

```python
number = 7
```

Using `if` / `else`, put the following into a variable called `result`:

- `"even"` if the number is even
- `"odd"` if it is odd

Then print `result`. Since 7 is odd, the expected output is:

```
odd
```

> Equality is checked with a double equals: `==`. A single equals (`=`) assigns,
