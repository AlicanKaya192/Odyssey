`verify(answer, sources)` dersteki doğrulamayı yazsın. Cevap `NOT_FOUND` ise
`True`. Değilse `[n]` biçiminde bir kaynak numarası olmalı, `1 <= n <=
len(sources)` sağlanmalı ve cevabın sayıları (numaranın kendisi hariç)
`sources[n - 1]`'in sayıları arasında olmalı; olmazsa `False`.

**Beklenen çıktı:**

```
True
False
False
```
