# Değerlendirme Algoritmaları

"Model %90 doğru" cümlesi tek başına neredeyse hiçbir şey söylemez. Bin
işlemden ellisi dolandırıcılıksa, hiçbir şeyi yakalamayan bir model de %95
doğrudur. Bu bölümde sınıflandırıcıyı değerlendiren ölçüleri sıfırdan yazıyor
ve scikit-learn ile karşılaştırıyoruz: karışıklık matrisi, kesinlik,
duyarlılık, F1, ROC eğrisi ve AUC.

## Dengesiz veri ve doğruluk tuzağı

Bin örnek, yaklaşık %5'i pozitif (sınıf 1). Bir modelin her örneğe verdiği
**puan** (score) var: büyükse "pozitif olabilir".

```python
import numpy as np

rng = np.random.default_rng(6)
n = 1000
y = (rng.random(n) < 0.05).astype(int)
# pozitiflerin puanı ortalamada yüksek
score = rng.normal(0, 1, n) + 1.8 * y
print(y.sum(), round(1 - y.mean(), 3))
```

```text
40 0.96
```

40 pozitif. Hep "negatif" diyen model %96 doğru.

## Karışıklık matrisi

Bir eşikle (burada 1,5) karar verince dört durum oluşur:

| | Tahmin 1 | Tahmin 0 |
|---|---|---|
| **Gerçek 1** | doğru pozitif (TP) | yanlış negatif (FN) |
| **Gerçek 0** | yanlış pozitif (FP) | doğru negatif (TN) |

```python
def confusion(y, pred):
    tp = int(((pred == 1) & (y == 1)).sum())
    fp = int(((pred == 1) & (y == 0)).sum())
    fn = int(((pred == 0) & (y == 1)).sum())
    tn = int(((pred == 0) & (y == 0)).sum())
    return tp, fp, fn, tn


pred = (score >= 1.5).astype(int)
tp, fp, fn, tn = confusion(y, pred)
print(tp, fp, fn, tn)
# "pozitif" dediklerimin kaçı doğru
precision = tp / (tp + fp)
# gerçek pozitiflerin kaçını buldum
recall = tp / (tp + fn)
f1 = 2 * precision * recall / (precision + recall)
print(round((tp + tn) / n, 3), round(precision, 3), round(recall, 3), round(f1, 3))
from sklearn.metrics import confusion_matrix, f1_score, precision_score, recall_score

print(confusion_matrix(y, pred).ravel().tolist())
print(round(precision_score(y, pred), 3), round(recall_score(y, pred), 3),
      round(f1_score(y, pred), 3))
```

```text
24 86 16 874
0.898 0.218 0.6 0.32
[874, 86, 16, 24]
0.218 0.6 0.32
```

Bu model 40 pozitifin 24'ünü buldu (**duyarlılık**, recall 0,6), ama "pozitif"
dediği 110 örneğin yalnızca 24'ü gerçekten pozitif (**kesinlik**, precision
0,218). Doğruluğu 0,898: hep "negatif" diyen modelden (0,96) **düşük**, yine
de pozitiflerin %60'ını yakalıyor. Dengesiz veride doğruluk yanlış soruyu
cevaplar. scikit-learn'ün `confusion_matrix`'i aynı dört sayıyı
`[TN, FP, FN, TP]` sırasıyla verir.

**F1** kesinlik ve duyarlılığın harmonik ortalaması: biri çok düşükse F1 de
düşük kalır.

## Eşik bir ödünleşme

```python
for t in (2.5, 1.5, 0.5):
    tp, fp, fn, tn = confusion(y, (score >= t).astype(int))
    print(t, round(tp / (tp + fp), 3), round(tp / (tp + fn), 3))
```

```text
2.5 0.526 0.25
1.5 0.218 0.6
0.5 0.102 0.9
```

Eşik düştükçe duyarlılık artıyor (0,25 → 0,6 → 0,9), kesinlik düşüyor
(0,526 → 0,218 → 0,102). Dolandırıcılıkta kaçırmak pahalıysa eşik düşer;
her alarmın bir insan tarafından incelenmesi pahalıysa eşik yükselir. Doğru
eşik modelin değil işin kararıdır.

## ROC eğrisi ve AUC

Tek bir eşik yerine **bütün eşikleri** bir arada görmek için puanları büyükten
küçüğe sıralayıp her adımda doğru pozitif oranını (duyarlılık, TPR) ve yanlış
pozitif oranını (FPR = FP / bütün negatifler) çizeriz: **ROC eğrisi**. Eğrinin
altındaki alan (**AUC**) eşikten bağımsız tek bir sayı verir.

```python
def roc_points(y, score):
    order = np.argsort(-score)                      # büyük puandan küçüğe
    ys = y[order]
    tpr = np.concatenate([[0], np.cumsum(ys) / ys.sum()])
    fpr = np.concatenate([[0], np.cumsum(1 - ys) / (1 - ys).sum()])
    return fpr, tpr


def auc(fpr, tpr):
    # yamuklar
    return float(((fpr[1:] - fpr[:-1]) * (tpr[1:] + tpr[:-1]) / 2).sum())


from sklearn.metrics import roc_auc_score

fpr, tpr = roc_points(y, score)
print(round(auc(fpr, tpr), 4), round(roc_auc_score(y, score), 4))
pos, neg = score[y == 1], score[y == 0]
# rastgele pozitif > rastgele negatif
pairs = (pos[:, None] > neg[None, :]).mean()
print(round(pairs, 4))
print(round(auc(*roc_points(y, rng.random(n))), 3))
```
