`threshold_for_recall(y, score, target)` fonksiyonunu yaz: puanları
büyükten küçüğe dolaş; eşik o puan olduğunda (`score >= eşik` pozitif)
duyarlılık ilk kez `target`'a ulaştığında o eşiği döndürsün. Yani hedefe
ulaşan **en yüksek** eşik. Puanlar birbirinden farklı.

**Beklenen çıktı:**

```
0.7
0.2
```
