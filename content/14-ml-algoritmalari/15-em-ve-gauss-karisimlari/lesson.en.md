# EM and Gaussian Mixtures

k-Means gives every point to **a single** cluster and treats every cluster as
round. A **Gaussian mixture model** (GMM) draws a more flexible picture: the
data came from a mixture of several normal distributions; each component has a
**weight** (share), a **mean** and a **variance** (or covariance matrix). The
way to find these parameters is the **EM algorithm**
(expectation–maximisation). In this section we write EM from scratch in one
dimension and compare it with scikit-learn's `GaussianMixture`, then look at
the elongated clusters k-Means struggles with and at choosing the number of
components.

## The EM algorithm

If we knew which point came from which component, we would compute each
component's mean and variance directly. If we knew the parameters, we would
compute which component each point may have come from. EM does both in turn:

1. **E step (expectation):** for every point, each component's
   **responsibility**: the probability that the point came from that
   component. `r = weight × density`, then divided so each row sums to 1.
2. **M step (maximisation):** the share, mean and variance are computed
   **weighted** by the responsibilities.

In every round the data's **log-likelihood** (the logarithm of the
probability the model gives the data) never decreases.

```python
import numpy as np
from sklearn.mixture import GaussianMixture

rng = np.random.default_rng(15)
x = np.concatenate([rng.normal(0, 1, 300), rng.normal(4, 1.5, 200)])


def normal_pdf(x, mu, var):
    return np.exp(-(x - mu) ** 2 / (2 * var)) / np.sqrt(2 * np.pi * var)


def em(x, w, mu, var, iters):
    w, mu, var = map(np.array, (w, mu, var))
    ll = []
    for _ in range(iters):
        dens = w * normal_pdf(x[:, None], mu, var)          # (n, k)
        ll.append(round(float(np.log(dens.sum(axis=1)).sum()), 3))
        r = dens / dens.sum(axis=1, keepdims=True)          # E step
        nk = r.sum(axis=0)                                  # M step
        w = nk / len(x)
        mu = (r * x[:, None]).sum(axis=0) / nk
        var = (r * (x[:, None] - mu) ** 2).sum(axis=0) / nk
    return w, mu, var, ll


w, mu, var, ll = em(x, [0.5, 0.5], [-1.0, 1.0], [1.0, 1.0], 200)
print(w.round(2), mu.round(2), var.round(2))
print(ll[:4], ll[-1])
print(all(b >= a for a, b in zip(ll, ll[1:])))
ref = GaussianMixture(2, weights_init=[0.5, 0.5], means_init=[[-1.0], [1.0]],
                      precisions_init=[[[1.0]], [[1.0]]], tol=1e-12, max_iter=1000)
ref.fit(x[:, None])
m, v = ref.means_.ravel(), ref.covariances_.ravel()
print(ref.weights_.round(2), m.round(2), v.round(2))
print(round(ref.score(x[:, None]) * len(x), 3))
```

## Soft assignment

In k-Means a point is either in the cluster or not. In a GMM every point has a
responsibility for every component; a point between two components is shared
between both:

```python
for v in (-1.0, 2.0, 2.5, 6.0):
    d = w * normal_pdf(v, mu, var)
    print(v, (d / d.sum()).round(3))
```

```text
-1.0 [1. 0.]
2.0 [0.622 0.378]
2.5 [0.263 0.737]
6.0 [0. 1.]
```

−1 and 6 are beyond doubt. The point at 2 belongs to the first component with
about 62%, the one at 2.5 to the second with about 74%. The boundary where the
responsibilities are equal is at about 2.17; that is exactly midway between the
two means, but by coincidence: the second component is wider, which pulls the
boundary to the left (with equal shares it would be at 2.0), and the first
component's larger share pushes it to the right. This uncertainty tells how
reliable a decision is.

## Elongated clusters

A GMM can give each component its own **covariance matrix**; a component need
not be round but can be a stretched, tilted ellipse. Let us generate two
clusters that are long horizontally and narrow vertically:

```python
from sklearn.cluster import KMeans
from sklearn.metrics import adjusted_rand_score

r2 = np.random.default_rng(1)
A = r2.normal(0, 1, (200, 2)) * [3, 0.5]
B = r2.normal(0, 1, (200, 2)) * [3, 0.5] + [0, 3]
X2 = np.vstack([A, B])
truth = np.repeat([0, 1], 200)
km = KMeans(2, n_init=10, random_state=0).fit(X2)
print(round(adjusted_rand_score(truth, km.labels_), 3))
for cov in ("spherical", "full"):
    g = GaussianMixture(2, covariance_type=cov, n_init=10, random_state=0).fit(X2)
    print(cov, round(adjusted_rand_score(truth, g.predict(X2)), 3))
```

```text
-0.002
spherical -0.002
full 0.98
```

k-Means cuts the clusters vertically (index below 0: no better than random);
the split that most reduces the squared distance is cutting the long axis in
two. A GMM with round components (`spherical`) falls into the same trap. A
GMM with full covariance (`full`) finds the two bands with 0.98.

## Choosing the number of components: BIC

The log-likelihood always rises as components are added (like the inertia in
k-Means). **BIC** (Bayesian information criterion) adds a penalty per
parameter: `BIC = p · ln n − 2 · log-likelihood` (`p` the number of
parameters, `n` the number of samples). The smaller one is chosen.

```python
for k in range(1, 6):
    g = GaussianMixture(k, n_init=5, random_state=0).fit(x[:, None])
    print(k, round(g.score(x[:, None]) * len(x), 1), round(g.bic(x[:, None]), 1))
```

```text
1 -1134.9 2282.3
2 -1064.4 2159.9
3 -1063.8 2177.3
4 -1062.0 2192.3
5 -1058.9 2204.7
```

The log-likelihood rises by 70 from 1 to 2, then each component adds between
0.6 and 3.1; but each component means 3 parameters (share, mean, variance) and
brings a penalty of `3 · ln 500 ≈ 18.6`. BIC takes its smallest value
(2159.9) at the true number of components, `k = 2`.

## Summary

- A GMM models the data as a mixture of weighted normal distributions.
- EM: responsibilities in the E step, weighted share, mean and variance in
  the M step; the log-likelihood never decreases but can get stuck in a local
  optimum.
- Soft assignment: every point has a probability for every component.
- Full covariance catches stretched, tilted clusters; k-Means cannot.
- The number of components is chosen with BIC (the smaller one).
