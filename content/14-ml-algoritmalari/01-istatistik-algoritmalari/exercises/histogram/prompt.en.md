Write the function `histogram(values, bins, low, high)`: split the range
`[low, high]` into `bins` equal bins and return the number of values in each
bin as a list. Values outside the range are not counted; a value exactly equal
to `high` goes into the last bin.

No `np.histogram`.

**Expected output:**

```
[1, 2, 1, 2]
```
