Ask the user for two integers (`x` and `y`). Print two lines: first the floor division, then the remainder, in the format of the example (`7 // 2 = 3` and `7 % 2 = 1`).

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py
x: 7
y: 2
7 // 2 = 3
7 % 2 = 1
```
