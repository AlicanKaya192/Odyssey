Kullanıcıdan iki tam sayı (`x` ve `y`) iste. İki satır yaz: önce tam sayı bölmesini, sonra kalanı, örnekteki biçimde (`7 // 2 = 3` ve `7 % 2 = 1`).

Örnek çalıştırma (soru metnini istediğin gibi yazabilirsin, yalnızca çıktın denetlenir):

```text
$ python cozum.py
x: 7
y: 2
7 // 2 = 3
7 % 2 = 1
```
