WRITING IN ALL CAPS IS LIKE YELLING. Best to use your "indoor voice" sometimes, writing entirely in lowercase.

Implement a program that prompts the user for input and then outputs **that same input in lowercase**. Punctuation and whitespace should be output unchanged. You are welcome, but not required, to prompt the user explicitly by passing a `str` of your own to `input`. (In CS50 the file is `indoor.py`.)

## How to test

The cases CS50 gives; Odyssey runs each one separately and compares your output. Your prompt can say anything you like; only your output is checked.

- Input `HELLO` → output `hello`
- Input `THIS IS CS50` → output `this is cs50`
- Input `50` → output `50`
