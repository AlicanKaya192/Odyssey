Even if you have not studied physics, you might have heard of E = mc²: `E` is energy (joules), `m` is mass (kilograms) and `c` is the speed of light (approximately `300000000` metres per second). Mass and energy are equivalent.

Implement a program that prompts the user for mass **as an integer** (in kilograms) and then outputs the equivalent number of joules **as an integer**. Assume that the user will input an integer. (In CS50 the file is `einstein.py`.)

## How to test

The cases CS50 gives; Odyssey runs each one separately and compares your output. Your prompt can say anything you like; only your output is checked.

- Input `1` → output `90000000000000000`
- Input `14` → output `1260000000000000000`
- Input `50` → output `4500000000000000000`
