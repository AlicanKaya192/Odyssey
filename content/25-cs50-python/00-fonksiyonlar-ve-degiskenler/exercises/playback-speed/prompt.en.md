Some people have a habit of speaking rather quickly, and it would be nice to slow them down, a la YouTube's 0.75 playback speed, or even by having them pause between words.

Implement a program that prompts the user for input and then outputs that same input, **replacing each space with `...`** (three periods). (In CS50 the file is `playback.py`.)

## How to test

The cases CS50 gives; Odyssey runs each one separately and compares your output. Your prompt can say anything you like; only your output is checked.

- Input `This is CS50` → output `This...is...CS50`
- Input `This is our week on functions` → output `This...is...our...week...on...functions`
- Input `Let's implement a function called hello` → output `Let's...implement...a...function...called...hello`
