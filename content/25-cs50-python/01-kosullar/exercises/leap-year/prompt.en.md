A year is a **leap year** if it is divisible by 4 but not by 100, **or** if it is divisible by 400. Ask the user for the year and print `leap year` or `not a leap year`. (2000 is a leap year, 1900 is not.)

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py
Year: 2024
leap year
```
