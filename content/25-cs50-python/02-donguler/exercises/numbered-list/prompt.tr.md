Başlangıç kodundaki `groceries` listesini numaralı yaz (`1. milk` gibi, numara 1'den başlasın). En sonda listede kaç eleman olduğunu `4 items` biçiminde yaz. Sayıyı elle yazma, **`len`** ile bul: listeye eleman eklenince program kendiliğinden doğru saymalı.

Örnek çalıştırma (soru metnini istediğin gibi yazabilirsin, yalnızca çıktın denetlenir):

```text
$ python cozum.py
1. milk
2. eggs
3. bread
4. apples
4 items
```
