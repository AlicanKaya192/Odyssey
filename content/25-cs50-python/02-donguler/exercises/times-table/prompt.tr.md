Kullanıcıdan bir sayı iste ve o sayının 1'den 10'a çarpım tablosunu yaz: her satır `3 x 1 = 3` biçiminde. **`for`** ve `range` kullan.

Örnek çalıştırma (soru metnini istediğin gibi yazabilirsin, yalnızca çıktın denetlenir):

```text
$ python cozum.py
Number: 3
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15
3 x 6 = 18
3 x 7 = 21
3 x 8 = 24
3 x 9 = 27
3 x 10 = 30
```
