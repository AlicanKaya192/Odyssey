When texting, it is not uncommon to shorten words, for example by omitting vowels; that is why Twitter was originally called `twttr`.

Implement a program that prompts the user for a string of text and then outputs that same text with all **vowels** (A, E, I, O and U, uppercase or lowercase) omitted. (In CS50 the file is `twttr.py`.)

## How to test

The cases CS50 gives; Odyssey runs each one separately and compares your output. Your prompt can say anything you like; only your output is checked.

- Input `Twitter` → output `Twttr`
- Input `What's your name?` → output `Wht's yr nm?`
- Input `CS50` → output `CS50`
- Input `AEIOU and aeiou` → output ` nd `
