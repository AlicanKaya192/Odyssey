Ask the user for a starting number. With a **`while`** loop, print every number from it down to 1 on its own line, then `Liftoff!` at the end. If the start is 0 or negative, only `Liftoff!` is printed.

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py
Start: 3
3
2
1
Liftoff!
```
