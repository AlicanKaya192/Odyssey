The `students` dict in the starter code maps each student to their house. Ask the user for a house name (case and spaces should not matter; the `title()` method turns `ravenclaw` into `Ravenclaw`). Go over the dict with **`for`**, print each student in that house on their own line in the dict's order, and at the end print how many were found in the form `2 students` (`0 students` if none).

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py
House: Gryffindor
Hermione
Harry
Ron
3 students
```
