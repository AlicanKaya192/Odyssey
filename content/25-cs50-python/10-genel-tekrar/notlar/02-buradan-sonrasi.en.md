CS50 Python is done. From here, the most useful thing is to use what you've
learned on a problem of your own choosing; that is also why CS50 ends the
course with a final project.

## Your own project

- Pick a problem that really interests you, small but finishable: a
  command-line tool that keeps a shopping list in a file, a score table for a
  game, a report that summarizes a CSV.
- Write the simplest working version first, then grow it. Write a test for
  each new piece (week 5).
- As the program grows, use the structure from this course: `main`, small
  functions, a class when needed, `if __name__ == "__main__":`.
- When you get stuck, read the last line of the error message, then look at
  the documentation. Looking up something you don't know is an ordinary part
  of programming.

## Continuing in Odyssey

- **Git:** keeping your code's history, going back when you break something
  and putting your project on GitHub. The path that will help you most before
  you start a project of your own.
- **Core Libraries:** the rest of the standard library (dates, paths,
  `collections`, `logging`, `dataclasses`, `typing`...) and then NumPy,
  pandas, Matplotlib.
- **Algorithms:** searching, sorting, recursion, data structures; measuring
  how fast code runs.
- **API:** a continuation of `requests` from week 4, then writing your own API
  with FastAPI.
- **SQL:** keeping your data in a database instead of a file, and querying it.
- **Data Science** and **Machine Learning:** what you did with CSVs, done at
  scale and with statistics.

For the order of the paths, see the **Roadmaps** screen; it has a suggested
order for a goal (e.g. data scientist, ML engineer).
