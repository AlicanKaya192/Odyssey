Kullanıcıdan GitHub profilinin adresini al ve kullanıcı adını çıkar: `Username: octocat`. Adres `https://` ya da `http://` ile başlayabilir ya da protokolsüz olabilir, `www.` olabilir de olmayabilir de; büyük/küçük harf fark etmez. Kullanıcı adı harf, rakam ve kısa çizgiden oluşur; arkasından gelen `/` ya da `?tab=...` kullanıcı adına girmez. Adres GitHub profili değilse (başka site ya da cümlenin içinde) `Not a GitHub profile` yaz.

Örnek çalıştırma (soru metnini istediğin gibi yazabilirsin, yalnızca çıktın denetlenir):

```text
$ python cozum.py
URL: https://github.com/davidjmalan
Username: davidjmalan
```
