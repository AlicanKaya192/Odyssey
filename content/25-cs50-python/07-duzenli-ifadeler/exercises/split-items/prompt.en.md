The user types a shopping list separated by commas or semicolons, with or without spaces around the separator (`apples, pears;plums ; figs`). Split it with `re.split` and print each item on its own line, without the spaces around it.

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py
Items: apples, pears;plums ; figs
apples
pears
plums
figs
```
