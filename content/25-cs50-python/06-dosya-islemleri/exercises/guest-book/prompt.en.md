Ask the user for their name and add it to the **end** of `guests.txt`, on its own line (earlier guests must not be erased). If the file does not exist, `"a"` mode creates it. You do not need to print anything; the check looks at the file afterwards.

Example run (the prompt can say anything you like; only your output and your file are checked):

```text
$ python cozum.py
Name: Bob
```
