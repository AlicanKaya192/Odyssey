`students.csv` has no header; each line holds a name and a house: `Harry,Gryffindor`. Split each line at the comma (`split`), unpack it into two variables and print the `Harry is in Gryffindor` sentences in alphabetical order.

Example run (the prompt can say anything you like; only your output and your file are checked):

```text
$ python cozum.py
Draco is in Slytherin
Harry is in Gryffindor
Hermione is in Gryffindor
Ron is in Gryffindor
```
