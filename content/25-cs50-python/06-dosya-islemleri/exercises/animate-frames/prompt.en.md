The exercise's folder has two costumes: `costume1.gif` and `costume2.gif`. Take **at least two** frame names from the command line and write them all, in the given order, into one animated GIF: `animation.gif` (`save_all=True`, `append_images`). The frame duration and looping are up to you; the check compares the frames and their order. With fewer than two frames, `sys.exit("Usage: python cozum.py FRAME FRAME ...")`. When you run the program, the GIF appears in the **Output** tab.

Example run (the prompt can say anything you like; only your output and your file are checked):

```text
$ python cozum.py costume1.gif costume2.gif

```
