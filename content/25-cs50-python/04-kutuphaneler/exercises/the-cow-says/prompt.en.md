Take **exactly one** name from the command line and have the `cowsay` package's cow say `hello, David` (`cowsay.cow`). With no name or more than one, `sys.exit("Usage: python cozum.py NAME")`.

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py David
  ____________
| hello, David |
  ============
            \
             \
               ^__^
               (oo)\_______
               (__)\       )\/\
                   ||----w |
                   ||     ||
```
