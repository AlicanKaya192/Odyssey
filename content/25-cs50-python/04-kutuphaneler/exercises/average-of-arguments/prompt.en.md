Take numbers from the command line (`python cozum.py 100 90`) and print their mean with `statistics.mean` to two decimal places (`95.00`). With no arguments, exit with `sys.exit("Usage: python cozum.py NUMBER ...")`; if any argument is not a number, with `sys.exit("Not a number")`.

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py 100 90
95.00
```
