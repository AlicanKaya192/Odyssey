Write a class named `Book`: its constructor takes a title (`title`) and an author (`author`) and stores them in instance variables of the same names; its `__str__` method returns a string like `Dune by Frank Herbert`. The program asks the user for the title and author, creates a `Book` and prints it with `print`.

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py
Title: Dune
Author: Frank Herbert
Dune by Frank Herbert
```
