`initials(name)` in `initials.py` returns a name's initials in uppercase: `initials("David Malan")` → `"DM"`, `initials("ada lovelace")` → `"AL"`, `initials("Cher")` → `"C"`.

Write at least two test functions in `test_initials.py`. When you test a function that returns a string, compare the result with the whole string. The broken versions do these: they do not uppercase lowercase letters, they take only the first word's letter, they put spaces between the letters.
