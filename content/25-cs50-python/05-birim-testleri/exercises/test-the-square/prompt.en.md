`calculator.py` is ready and read-only; its `square(n)` returns a number's square. Write `assert` lines in the `test_square` function in `test_calculator.py`: positive numbers, negative numbers and zero.

Odyssey first runs your test with the correct `calculator.py` (it must pass), then with **deliberately broken** versions of `square` (your test must fail with each). If you try only `square(2)`, you miss a `square` written as `n + n`.
