Kullanıcıdan bir tam sayı iste. Tam sayıysa iki katını yaz; değilse program çökmesin, `Not a number` yazsın. `try` / `except ValueError` / `else` kullan: iki katını yazan satır `else`'te dursun.

Örnek çalıştırma (soru metnini istediğin gibi yazabilirsin, yalnızca çıktın denetlenir):

```text
$ python cozum.py
Number: 21
42
```
