Başlangıç kodundaki `colors` listesinden kullanıcının yazdığı konumdaki rengi yaz (konum 0'dan başlar). Girdi tam sayı değilse `Not a number`, listede öyle bir konum yoksa `No such position` yaz. Listenin uzunluğunu `if` ile sorma; `IndexError`'ı yakala.

Örnek çalıştırma (soru metnini istediğin gibi yazabilirsin, yalnızca çıktın denetlenir):

```text
$ python cozum.py
Position: 0
red
```
