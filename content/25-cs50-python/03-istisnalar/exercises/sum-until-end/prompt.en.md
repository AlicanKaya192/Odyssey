Ask the user for numbers, one per line, until they end the input (`Ctrl+D`, on Windows `Ctrl+Z` + Enter; it reaches the program as an `EOFError`). Ignore lines that are not integers. When the input ends, print the sum of all the numbers; `0` if there were none.

In Odyssey you do not type the input yourself; the check feeds each case's lines and then ends the input.

Example run (the prompt can say anything you like; only your output is checked):

```text
$ python cozum.py
Number: 1
Number: 2
Number: 3
Number: 6
```
