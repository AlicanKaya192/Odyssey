`wrong_steps(text)` hazır `STEP` düzenli ifadesiyle metindeki
`a op b = c` işlemlerini bulsun (`op`: `+`, `-`, `*`, `/`), her birini
yeniden hesaplasın ve sonucu yazılandan 0.005'ten fazla farklı olanları
`"a op b = c"` metni olarak, metindeki sırasıyla döndürsün.

**Beklenen çıktı:**

```
['40 / 4 = 12']
[]
```
