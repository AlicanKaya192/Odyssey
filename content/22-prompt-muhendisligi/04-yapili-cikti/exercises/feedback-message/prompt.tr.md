`feedback(errors)` hata listesinden modele gidecek mesajı kursun:
`"Your answer was not valid: "` + hataların `"; "` ile birleşimi +
`". Reply with the JSON object only."`. Liste boşsa boş metin döndür.

**Beklenen çıktı:**

```
Your answer was not valid: urgent must
be true or false. Reply with the JSON
object only.
''
```
