Write the function `next_greater(values)` with a **monotonic stack**: it
returns a list holding, for each item, the first value to its right that is
**greater** than it, or `-1` if there is none.

On the hundred-thousand-item decreasing list on the last line, looking right
from every item runs out of time.

**Expected output:**

```
[5, 3, 5, 5, -1]
[-1, -1, -1]
[-1, -1, -1]
```
