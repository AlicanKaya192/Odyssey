Write the function `group_sizes(n, pairs)` with **union-find**: people
`0`..`n − 1`, `pairs` are `[a, b]` friendships. Friendship is transitive (a
friend's friend is in the same group). It returns the sizes of the groups as a
list sorted **from largest to smallest**.

**Expected output:**

```
[3, 2, 1, 1]
[1, 1, 1]
```
