`fit_scaler(train, test)` bir `StandardScaler`'ı **yalnızca eğitim** verisiyle
fit etsin ve test verisini onunla dönüştürsün. `[ortalamalar, test]`
döndürsün: `mean_` 3 basamak, dönüştürülmüş test 2 basamaklı liste
listesi. Başlangıç kodu iki veriyi birleştirip öyle fit ediyor: sızıntı.

**Beklenen çıktı:**

```
[[2.0, 20.0], [[0.0, 3.0]]]
```
