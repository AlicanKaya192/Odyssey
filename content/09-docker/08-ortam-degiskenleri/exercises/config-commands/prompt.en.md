**What to do:** write three commands in `commands.sh`, in order:

1. Run the `app` image with the environment variable `APP_ENV=production`;
   remove it when done.
2. Run the `app` image with the variables in the file `app.env`; remove it
   when done.
3. Build the `app` image from the Dockerfile in this folder with the build
   argument `VERSION=2.1`.
