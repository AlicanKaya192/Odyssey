Write the six-line skeleton from the lesson yourself. Follow the order in
the comments.

1. Start from the `python:3.13-slim` image.
2. The working folder is `/app`.
3. First copy only `requirements.txt`.
4. Install the packages with `pip install --no-cache-dir -r requirements.txt`.
5. Then copy everything in the folder.
6. When the container runs, `python app.py` should run.
