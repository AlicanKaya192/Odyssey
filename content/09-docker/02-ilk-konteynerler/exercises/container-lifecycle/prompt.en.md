The `sleeper` container from the previous exercise is running. Talk to it
and end its life.

**What to do:** write five commands in `commands.sh`, in order:

1. List all containers, finished ones included.
2. Run the `ps` command inside `sleeper` (without starting a new container).
3. Look at `sleeper`'s output.
4. Stop `sleeper`.
5. Remove `sleeper`.
