Collect the last steps of the installation in one file.

**What to do:** write four commands in `commands.sh`, in order:

1. The command that shows Docker's version (Client and Server).
2. The command that downloads the `python:3.13-slim` image.
3. The command that downloads the `alpine:3.22` image.
4. The command that lists the images on the computer.

Odyssey reads and checks the commands; it does not run them. Run them in
PowerShell yourself as well: the following exercises of the path use these
two images.
