Do by hand what Compose does.

**What to do:** write five commands in `commands.sh`, in order:

1. Create a network called `shopnet`.
2. Run the `shop-api` image named `api`, in the background, on the `shopnet`
   network.
3. Run the `shop-web` image on the `shopnet` network; remove it when done.
4. List the networks.
5. Show the details of `shopnet`.
