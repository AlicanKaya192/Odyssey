Write the function `shuffled(items, seed)`: take a **copy** of the list
(`list(items)`), shuffle the copy with the `shuffle` method of a
`random.Random(seed)` generator and return the copy. The given list must not
change.

**Expected output:**

```
[2, 7, 6, 5, 8, 1, 3, 4]
[1, 2, 3, 4, 5, 6, 7, 8]
```
