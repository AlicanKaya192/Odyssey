Product codes are two uppercase letters, a dash and four digits:
`AB-1234`. Write the function `is_product_code(code)`: return `True` if the
code is exactly in this format, otherwise `False`. The starter code uses
`search`; `XAB-1234` is valid for it too.

**Expected output:**

```
AB-1234 True
ab-1234 False
AB-123 False
XAB-1234 False
```
