Move between units. This exercise has no file, only arithmetic.

**What to do:**

1. Print how many MB `5_000_000` bytes is, rounded to two decimals.
2. Print how many bytes `3` GB is.
3. Print how many GB a disk the maker calls "1 TB" (`10**12` bytes) shows up
   as in Windows, rounded to one decimal.
4. Print how many times a `250` MB file fits into `4` GB of memory, as a
   whole number (`//`).

**Expected output:**

```
4.77
3221225472
931.3
16
```

1 MB = `1024**2` bytes, 1 GB = `1024**3` bytes.
