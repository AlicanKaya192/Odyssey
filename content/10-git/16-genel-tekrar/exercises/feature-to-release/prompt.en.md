Add a menu item to the shop and release a new version:

- Create the `cake` branch; add `cake 5` to the end of `menu.txt` and commit with the message `Add cake`.
- Bring it into `main` **with a merge commit** (ready-made message), delete the branch.
- Put an annotated `v1.1` tag on `main` (`Cake release`).
- Push `main` and the tag to GitHub.
