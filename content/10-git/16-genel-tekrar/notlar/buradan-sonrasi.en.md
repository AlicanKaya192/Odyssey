This track covered Git's everyday use. If you want to go further, here are
the topics and resources to look at.

## First: a real project

- Create a GitHub account (if you don't have one) and a repository.
- Apply this track's flow to your own code: branch, small commits, PR,
  merge, tag.
- A small contribution to an open source project (even a typo fix): fork,
  branch, PR.

## Advanced topics

| Topic | What it's for |
|---|---|
| `git bisect` | Finds the commit that introduced a bug with a binary search. |
| `git worktree` | Opens two branches of the same repository in separate folders. |
| `git submodule` | Using one repository inside another. |
| Hooks (`.git/hooks`) | Automatic checks before a commit / push (e.g. formatting). |
| `.gitattributes` | Settings for line endings, binary files, diff behaviour. |
| Git LFS | Keeping big files outside the repository. |
| GitHub Actions | Running the tests on every push (CI). |
| Signed commits | Proving a commit really came from you. |

## Resources

- **Pro Git** (git-scm.com/book): Git's official book; free, with translations.
- **git-scm.com/docs**: the full documentation of every command (`git help
  <command>` opens the same).
- **GitHub Docs** (docs.github.com): pull requests, Actions, settings.
- **learngitbranching.js.org**: a game for trying branches visually.
