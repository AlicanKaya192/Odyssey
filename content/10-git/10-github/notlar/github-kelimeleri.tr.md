GitHub'da karşına çıkacak kelimeler. Bir kısmı Git'in kendisinde yok;
yalnızca GitHub'ın özellikleri.

| Kelime | Anlamı |
|---|---|
| **Repository** | Depo. |
| **Fork** | Başkasının deposunun senin hesabındaki kopyası. |
| **Clone** | Depoyu bilgisayarına indirmek (Git komutu). |
| **Pull request (PR)** | Bir dalı başka bir dala birleştirme isteği ve tartışması. |
| **Review** | PR'ı gözden geçirme: yorum, onay, değişiklik isteği. |
| **Issue** | Hata bildirimi, istek ya da görev; numarası var (`#12`). |
| **Star** | Depoyu beğenmek / yer imine eklemek. |
| **Watch** | Depodaki hareketlerden bildirim almak. |
| **Release** | Bir etikete (13) bağlı, indirilebilir dosyaları olan yayın sayfası. |
| **Actions** | Push ya da PR'da kendiliğinden çalışan işler (test, derleme). |
| **Gist** | Tek dosyalık küçük paylaşımlar. |
| **Collaborator** | Depoya yazma izni olan kişi. |
| **Organization** | Birden çok kişinin ortak hesabı (şirket, ekip). |
| **Default branch** | Deponun ana dalı (çoğu zaman `main`); PR'lar varsayılan olarak buraya açılır. |
| **Branch protection** | Ana dala doğrudan push'u kapatan, PR ve onay isteyen kural. |
| **README** | Ana sayfada çizilen tanıtım dosyası. |
| **LICENSE** | Kodun hangi koşullarla kullanılabileceği (MIT, GPL...). |

## Git'te mi, GitHub'da mı?

| Git (bilgisayarında) | GitHub (sitede) |
|---|---|
| commit, branch, merge, rebase, tag | pull request, fork, issue, review |
| `git clone`, `git push`, `git pull` | depo oluşturmak, izinler, Actions |

Git'i GitHub olmadan kullanabilirsin; GitHub'ı Git olmadan kullanamazsın.
