Words you'll meet on GitHub. Some don't exist in Git itself; they are only
GitHub features.

| Word | Meaning |
|---|---|
| **Repository** | A repository. |
| **Fork** | A copy of someone else's repository in your account. |
| **Clone** | Downloading a repository to your computer (a Git command). |
| **Pull request (PR)** | A request, with discussion, to merge one branch into another. |
| **Review** | Going through a PR: comments, approval, change requests. |
| **Issue** | A bug report, request or task; it has a number (`#12`). |
| **Star** | Liking / bookmarking a repository. |
| **Watch** | Getting notifications about a repository's activity. |
| **Release** | A release page tied to a tag (13), with downloadable files. |
| **Actions** | Jobs that run by themselves on a push or PR (tests, builds). |
| **Gist** | Small single-file shares. |
| **Collaborator** | Someone with write access to the repository. |
| **Organization** | A shared account for several people (a company, a team). |
| **Default branch** | The repository's main branch (usually `main`); PRs target it by default. |
| **Branch protection** | A rule that blocks direct pushes to the main branch and requires PRs and approval. |
| **README** | The introduction file rendered on the home page. |
| **LICENSE** | The terms under which the code may be used (MIT, GPL...). |

## In Git or on GitHub?

| Git (on your computer) | GitHub (on the site) |
|---|---|
| commit, branch, merge, rebase, tag | pull request, fork, issue, review |
| `git clone`, `git push`, `git pull` | creating repositories, permissions, Actions |

You can use Git without GitHub; you can't use GitHub without Git.
