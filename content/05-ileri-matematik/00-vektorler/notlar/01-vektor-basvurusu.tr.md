Dersteki her şeyin kısa hâli. Bir soruda takıldığında buraya dön.

## Gösterim

| Yazılış | Anlamı |
|---|---|
| $\mathbf{v}$, $\vec{v}$ | vektör (kalın ya da oklu) |
| $v_1, v_2, \ldots$ | vektörün bileşenleri |
| $\mathbb{R}^n$ | $n$ sayıdan oluşan vektörlerin kümesi |
| $\overrightarrow{AB}$ | $A$'dan $B$'ye giden vektör |
| $\|\mathbf{v}\|$ | vektörün uzunluğu (normu) |
| $\hat{\mathbf{v}}$ | $\mathbf{v}$ yönündeki birim vektör |
| $\mathbf{0}$ | sıfır vektörü, $(0, 0, \ldots, 0)$ |
| $\mathbf{i} = (1, 0)$, $\mathbf{j} = (0, 1)$ | düzlemin temel birim vektörleri |

## İşlemler

| İşlem | Formül | Örnek |
|---|---|---|
| İki noktadan vektör | $\overrightarrow{AB} = B - A$ | $A(1,1), B(4,5) \Rightarrow (3, 4)$ |
| Toplama | $(v_1 + w_1,\ v_2 + w_2)$ | $(4,1) + (1,3) = (5, 4)$ |
| Çıkarma | $(v_1 - w_1,\ v_2 - w_2)$ | $(4,1) - (1,3) = (3, -2)$ |
| Skalerle çarpma | $(c\,v_1,\ c\,v_2)$ | $3\,(2, -1) = (6, -3)$ |
| Doğrusal kombinasyon | $a\,\mathbf{v} + b\,\mathbf{w}$ | $2(1,2) - (3,1) = (-1, 3)$ |
| Uzunluk | $\sqrt{v_1^2 + \cdots + v_n^2}$ | $\|(3, 4)\| = 5$ |
| Birim vektör | $\mathbf{v} / \|\mathbf{v}\|$ | $(3,4)/5 = (0.6, 0.8)$ |
| Uzaklık | $\|\mathbf{b} - \mathbf{a}\|$ | $d\big((2,3), (5,7)\big) = 5$ |

## Kurallar

- Toplama değişmeli ve birleşmeli: $\mathbf{v} + \mathbf{w} = \mathbf{w} + \mathbf{v}$.
- Skaler dağılır: $c\,(\mathbf{v} + \mathbf{w}) = c\,\mathbf{v} + c\,\mathbf{w}$ ve $(a + b)\,\mathbf{v} = a\,\mathbf{v} + b\,\mathbf{v}$.
- Uzunluk: $\|c\,\mathbf{v}\| = |c|\,\|\mathbf{v}\|$.
- Üçgen eşitsizliği: $\|\mathbf{v} + \mathbf{w}\| \le \|\mathbf{v}\| + \|\mathbf{w}\|$.
- $\overrightarrow{BA} = -\overrightarrow{AB}$.

## Tanımsız olanlar

- Farklı boyutlu iki vektörü toplamak ya da çıkarmak.
- Bir vektöre sayı eklemek ($\mathbf{v} + 5$).
- Sıfır vektörünün birim vektörü (sıfıra bölme).

## Akılda tutulacak Pisagor üçlüleri

Uzunluk sorularında sık çıkan, tam sayı sonuç veren üçlüler:

| Bileşenler | Uzunluk |
|---|---|
| $(3, 4)$ | $5$ |
| $(5, 12)$ | $13$ |
| $(8, 15)$ | $17$ |
| $(6, 8)$ | $10$ |
| $(1, 2, 2)$ | $3$ |
| $(2, 3, 6)$ | $7$ |

Bir üçlünün katları da işe yarar: $(9, 12)$'nin uzunluğu $3 \cdot 5 = 15$.
