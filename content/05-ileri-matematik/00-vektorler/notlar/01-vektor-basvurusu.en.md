## Notation

| Written | Meaning |
|---|---|
| $\mathbf{v}$, $\vec{v}$ | a vector (bold or with an arrow) |
| $v_1, v_2, \ldots$ | the components of the vector |
| $\mathbb{R}^n$ | the set of vectors made of $n$ numbers |
| $\overrightarrow{AB}$ | the vector from $A$ to $B$ |
| $\|\mathbf{v}\|$ | the length (norm) of the vector |
| $\hat{\mathbf{v}}$ | the unit vector in the direction of $\mathbf{v}$ |
| $\mathbf{0}$ | the zero vector, $(0, 0, \ldots, 0)$ |
| $\mathbf{i} = (1, 0)$, $\mathbf{j} = (0, 1)$ | the basic unit vectors of the plane |

## Operations

| Operation | Formula | Example |
|---|---|---|
| Vector from two points | $\overrightarrow{AB} = B - A$ | $A(1,1), B(4,5) \Rightarrow (3, 4)$ |
| Addition | $(v_1 + w_1,\ v_2 + w_2)$ | $(4,1) + (1,3) = (5, 4)$ |
| Subtraction | $(v_1 - w_1,\ v_2 - w_2)$ | $(4,1) - (1,3) = (3, -2)$ |
| Scaling | $(c\,v_1,\ c\,v_2)$ | $3\,(2, -1) = (6, -3)$ |
| Linear combination | $a\,\mathbf{v} + b\,\mathbf{w}$ | $2(1,2) - (3,1) = (-1, 3)$ |
| Length | $\sqrt{v_1^2 + \cdots + v_n^2}$ | $\|(3, 4)\| = 5$ |
| Unit vector | $\mathbf{v} / \|\mathbf{v}\|$ | $(3,4)/5 = (0.6, 0.8)$ |
| Distance | $\|\mathbf{b} - \mathbf{a}\|$ | $d\big((2,3), (5,7)\big) = 5$ |

## Rules

- Addition is commutative and associative: $\mathbf{v} + \mathbf{w} = \mathbf{w} + \mathbf{v}$.
- Scalars distribute: $c\,(\mathbf{v} + \mathbf{w}) = c\,\mathbf{v} + c\,\mathbf{w}$ and $(a + b)\,\mathbf{v} = a\,\mathbf{v} + b\,\mathbf{v}$.
- Length: $\|c\,\mathbf{v}\| = |c|\,\|\mathbf{v}\|$.
- Triangle inequality: $\|\mathbf{v} + \mathbf{w}\| \le \|\mathbf{v}\| + \|\mathbf{w}\|$.
- $\overrightarrow{BA} = -\overrightarrow{AB}$.

## What is undefined

- Adding or subtracting two vectors of different dimensions.
- Adding a number to a vector ($\mathbf{v} + 5$).
- The unit vector of the zero vector (division by zero).

## Pythagorean triples worth remembering

Triples that come up often in length questions and give whole-number results:

| Components | Length |
|---|---|
| $(3, 4)$ | $5$ |
| $(5, 12)$ | $13$ |
| $(8, 15)$ | $17$ |
| $(6, 8)$ | $10$ |
| $(1, 2, 2)$ | $3$ |
| $(2, 3, 6)$ | $7$ |

Multiples of a triple work too: the length of $(9, 12)$ is $3 \cdot 5 = 15$.
