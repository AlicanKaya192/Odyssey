Write the function `psi_label(value)` that turns a PSI value into a label by the rule of thumb:

- Below `0.1`: `"stable"`
- Between `0.1` and `0.25` (both included): `"moderate"`

**Expected output:**

```

0.1 moderate
0.229 moderate
0.25 moderate
0.456 large
```
