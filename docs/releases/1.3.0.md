# Odyssey 1.3.0 — CS50 Python and MLOps

Harvard's CS50 Python course arrives in Odyssey: each week's lecture video
with English or Turkish subtitles, a lesson in both languages and the
week's problem set, checked by Odyssey. The System Design path gets its
second module, MLOps and ML System Design.

## Added
- **The CS50 Python path.** Harvard's CS50 Introduction to Programming with
  Python, inside Odyssey (11 sections): each week's lecture video plays in
  the program, with English or Turkish subtitles; alongside it a lesson in
  both languages, lecture notes, a quiz, exercises from the lecture and, in
  the same section, that week's CS50 problem set. Odyssey checks the
  problems; no account or extra setup is needed. Weeks: Functions and
  Variables, Conditionals, Loops, Exceptions, Libraries, Unit Tests, File
  I/O, Regular Expressions, Object-Oriented Programming, Et Cetera and an
  Overall Review. A small surprise badge awaits anyone who starts CS50.
- New badges and the "Chiron" title for CS50 Python; the Python terms of
  the glossary are explained in the CS50 lessons too. A PDF your code
  produces (like the Shirtificate) shows its first page in the Output tab.
- **The second module of the System Design path: MLOps and ML System
  Design** (17 sections). Taking a model out of the notebook and turning it
  into a reliable system: reproducible training, data validation, data and
  model versioning, experiment tracking, the model registry and quality
  gate, serving, training-serving skew, monitoring, data and concept drift,
  shadow, canary and A/B tests, scaling and ML system design; at the end, a
  pipeline that monitors, retrains and passes the new model through a gate
  every month by itself. The whole module uses a single example (subscription
  churn), and every result is shown by measuring it.
- New badges, the "Argus" title, MLOps terms in the Glossary, MLOps sections
  in the Data Engineer and ML Engineer routes.
- **Finding a date and resolving it.** New parts in NLP Fundamentals ›
  Rule-Based Information Extraction and Prompt Engineering › Structured
  Output and Validation: turning a relative phrase such as "tomorrow at
  7pm" into a calendar time with a reference time and time zone, asking
  instead of guessing when a phrase such as "tomorrow at 7" is ambiguous,
  reading `03/04/2026` with an explicit US or day-first policy, and catching
  a model answer that passes the schema but is ambiguous in meaning. New
  exercises score accepted, rejected and needs-clarification cases
  separately.
- **Quick reference drawer.** Opens from every screen with the button in the
  bottom bar or `Ctrl+R`: in a section you get that section's reference card
  ("Command Sheet", "… Reference" and so on), elsewhere the one from the
  section you studied last. The notes of other sections are searched from
  the box at the top. The lesson and the exercise stay usable while the
  drawer is open, so you can check commands while writing an exercise.
- **Topics to review after a quiz.** The result card lists the lesson or
  lecture note headings the questions you got wrong are based on; clicking
  one opens the lesson or the note at that heading. "See my mistakes" also
  has a "Go to the lesson" or "Go to the note" link under every wrong
  question.
- **"System" theme.** In Settings › Appearance, next to Light and Dark: when
  the Windows theme changes, the program changes with it right away.

## Changed
- **Levels were widened for the new paths.** The XP needed for the next level
  went up a little; your current level may drop by a few steps. The titles
  you have earned stay yours.
- **The My Notes sidebar is tidier.** Only modules that have notes and
  your own folders are listed; empty modules are one click away. A search
  box at the top looks through note titles and text, and long module names
  wrap onto two lines instead of being cut off.

## Fixed
- **The comparison boxes in the lessons are side by side.** In some
  "not like this / like this" boxes in the Python Fundamentals and CI/CD
  lessons, the two sides were drawn one under the other as a single block.
- **Correct tests no longer fail in test-writing exercises.** When checking
  whether your tests catch broken code, some exercises (for example CI/CD ›
  Automated Tests) occasionally did not run the broken version at all, so
  well-written tests could fail with "did not catch the bug".
- **Fewer short stutters when moving between screens.** Going back from
  a section to the Learning Path and opening a section are smoother, and
  the interface no longer stutters a few seconds after start-up while
  search is being prepared.

## Download

1. Download `Odyssey-1.3.0-setup.exe` below.
2. Run it. Odyssey installs for your own user account — no administrator
   rights needed — and puts a shortcut in the Start menu and on your desktop.

Windows may show "Windows protected your PC" the first time, because the
installer is not code-signed yet. Click **More info**, then **Run anyway**.

If Odyssey 1.2.0 is already installed, it offers this update on its own and
downloads only the files that changed (`Odyssey-1.3.0-patch-1.2.0.exe`)
instead of the full installer; your progress, notes and settings are kept.
Older versions download the full installer.

The CS50 Python videos play from YouTube and need an internet connection;
everything else works offline. The Docker exercises need Docker Desktop,
which you install separately; the other paths need nothing extra.

# Odyssey 1.3.0 — CS50 Python ve MLOps

Harvard'ın CS50 Python dersi Odyssey'de: her haftanın ders videosu
İngilizce ya da Türkçe altyazıyla, iki dilde ders ve haftanın problem
seti, denetimi Odyssey'de. Sistem Tasarımı patikasına ikinci modül geldi:
MLOps ve ML Sistem Tasarımı.

## Eklendi
- **CS50 Python patikası.** Harvard'ın CS50 Python ile Programlamaya Giriş
  dersi, Odyssey'nin içinde (11 bölüm): her haftanın ders videosu
  programda oynuyor, İngilizce ya da Türkçe altyazıyla; yanında iki dilde
  ders, ders notları, sınav, dersten alıştırmalar ve aynı bölümde o
  haftanın CS50 problem seti. Problemleri Odyssey denetliyor; hesap ya da
  ek kurulum gerekmiyor. Haftalar: Fonksiyonlar ve Değişkenler, Koşullar,
  Döngüler, İstisnalar, Kütüphaneler, Birim Testleri, Dosya İşlemleri,
  Düzenli İfadeler, Nesne Yönelimli Programlama, Son Dokunuşlar ve Genel
  Tekrar. CS50'ye başlayanı küçük bir sürpriz rozet bekliyor.
- CS50 Python için yeni rozetler ve "Kiron" unvanı; sözlükteki Python
  terimleri CS50 derslerinde de açıklamalı. Kodunuzun ürettiği PDF
  (Shirtificate gibi) Çıktı sekmesinde ilk sayfasıyla görünüyor.
- **Sistem Tasarımı patikasının ikinci modülü: MLOps ve ML Sistem
  Tasarımı** (17 bölüm). Bir modeli defterden çıkarıp güvenilir bir sisteme
  dönüştürmek: tekrarlanabilir eğitim, veri doğrulama, veri ve model
  sürümleme, deney takibi, model kaydı ve kalite kapısı, model sunma,
  eğitim-sunma farkı, izleme, veri ve kavram kayması, gölge, kanarya ve
  A/B testi, ölçeklenme ve ML sistem tasarımı; sonunda her ay kendiliğinden
  izleyen, yeniden eğiten ve yeni modeli kapıdan geçiren bir hat. Bütün
  modül tek bir örnek (abonelik iptali) üzerinde, her sonuç ölçülerek
  anlatılıyor.
- Yeni rozetler, "Argos" unvanı, sözlükte MLOps terimleri, Veri Mühendisi
  ve ML Mühendisi rotalarında MLOps bölümleri.
- **Tarihi bulmak ve çözmek.** NLP Temelleri › Kural Tabanlı Bilgi Çıkarma
  ile Prompt Mühendisliği › Yapılı Çıktı ve Doğrulama bölümlerine yeni
  kısımlar: "tomorrow at 7pm" gibi göreli bir ifadeyi referans an ve saat
  dilimiyle takvim saatine çevirmek, "tomorrow at 7" gibi belirsiz bir
  ifadede tahmin etmek yerine sormak, `03/04/2026`'yı açık bir ABD ya da
  gün-önce kuralıyla okumak ve şemadan geçen ama anlamca belirsiz bir model
  cevabını yakalamak. Yeni alıştırmalar kabul, ret ve açıklama gereken
  durumları ayrı ayrı puanlıyor.
- **Hızlı başvuru çekmecesi.** Alt şeritteki düğme ya da `Ctrl+R` ile her
  ekrandan açılıyor: bölümdeyseniz o bölümün başvuru kartı ("Komut Kartı",
  "… Başvurusu" gibi), değilseniz en son çalıştığınız bölümünkü. Başka
  bölümlerin notları üstteki kutudan aranıyor. Çekmece açıkken ders ve
  alıştırma kullanılmaya devam ediyor; alıştırma yazarken komutlara bakmak
  için.
- **Sınavdan sonra tekrar edilecek başlıklar.** Sonuç kartında yanlış
  yaptığınız soruların dayandığı ders ya da ders notu başlıkları
  listeleniyor; birine tıklayınca ders ya da not o başlıkta açılıyor.
  "Yanlışlarımı gör"de de her yanlış sorunun altında "Derse git" ya da
  "Nota git" bağlantısı var.
- **"Sistem" teması.** Ayarlar › Görünüm'de Açık ve Koyu'nun yanında:
  Windows'un teması değişince program da hemen değişiyor.

## Değişti
- **Seviyeler yeni patikalara göre genişletildi.** Bir sonraki seviye için
  gereken XP biraz arttı; mevcut seviyeniz birkaç basamak düşebilir.
  Kazandığınız unvanlar sizde kalıyor.
- **Notlarım'ın sol menüsü sadeleşti.** Yalnızca notu olan modüller ve
  kendi klasörleriniz görünüyor; boş modüller tek tıkla açılıyor. Üstte
  notların adında ve içinde arama var, uzun modül adları kırpılmadan iki
  satıra iniyor.

## Düzeltildi
- **Derslerdeki karşılaştırma kutuları yan yana görünüyor.** Python
  Temelleri ve CI/CD derslerindeki bazı "şöyle değil / böyle"
  kutularında iki taraf alt alta, tek blok hâlinde çiziliyordu.
- **Test yazma alıştırmalarında doğru testler artık düşmüyor.** Testinizin
  bozuk kodu yakalayıp yakalamadığı denetlenirken bazı alıştırmalarda
  (örneğin CI/CD › Otomatik Testler) bozuk sürüm arada bir hiç
  çalıştırılmıyordu; iyi yazılmış testler de "hatayı yakalamadı" diye
  düşebiliyordu.
- **Ekranlar arasında geçerken kısa takılmalar azaldı.** Bölümden
  Öğrenme Yolu'na dönmek ve bir bölümü açmak daha akıcı; program
  açıldıktan birkaç saniye sonra arama hazırlanırken arayüz artık
  takılmıyor.

## İndirme

1. Aşağıdan `Odyssey-1.3.0-setup.exe` dosyasını indirin.
2. Çalıştırın. Odyssey kendi kullanıcı hesabınıza kuruluyor — yönetici
   yetkisi gerekmiyor — ve Başlat menüsüne ve masaüstüne kısayol koyuyor.

Windows ilk seferde "Windows kişisel bilgisayarınızı korudu" diyebilir,
çünkü kurulum dosyası henüz imzalı değil. **Ek bilgi**'ye, ardından **Yine
de çalıştır**'a tıklayın.

Odyssey 1.2.0 kuruluysa bu güncellemeyi kendisi öneriyor ve kurulum
dosyasının tamamı yerine yalnızca değişen dosyaları indiriyor
(`Odyssey-1.3.0-patch-1.2.0.exe`); ilerlemeniz, notlarınız ve ayarlarınız
korunuyor. Daha eski sürümler tam kurulum dosyasını indiriyor.

CS50 Python videoları YouTube'dan oynatıldığı için internet bağlantısı
istiyor; geri kalan her şey çevrimdışı çalışıyor. Docker alıştırmaları için
ayrıca Docker Desktop kurmanız gerekiyor; öbür patikalar ek bir şey
istemiyor.
