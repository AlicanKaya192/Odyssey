# Odyssey 1.2.0 — System Design: CI/CD and DevOps

A new path opens: System Design. Its first module, CI/CD and DevOps, goes
from automated tests to a full GitHub Actions pipeline for a Python
project. In the workflow exercises you write the YAML file yourself and
Odyssey checks it against GitHub's rules — nothing is run and no account is
needed.

## Added
- **The System Design (CI/CD) path is open.** The first module, **CI/CD
  and DevOps** (17 sections): automated tests and quality gates, the
  structure of a GitHub Actions workflow, triggers, jobs and dependencies,
  matrices, caching, artifacts and packaging, secrets, versioning and tags,
  deployment strategies, CI/CD with containers, branch strategy and PR
  checks, flaky tests, ending with the full pipeline of a Python project.
  The second module, **MLOps and ML System Design**, comes in a later
  release.
- New badges, the "Hephaestus" title, CI/CD terms in the glossary, and a
  CI/CD step in the Data Engineer and ML Engineer routes.

## Fixed
- **Odyssey opens faster right after the computer starts.** When the
  application had not been used for a while, the start-up animation could
  wait on "Preparing" for more than 15 seconds. The component that shows
  lessons, notes and release notes is now prepared in the background after
  Odyssey opens; the window no longer waits for it.
- **The Glossary shows the headings of the NLP and Generative AI terms.**
  These two groups had a raw label instead of a heading.

## In numbers

Fourteen complete paths and the first module of System Design — 438
sections, 11453 quiz questions, 1935 exercises (85 of them in the Git
terminal), 300 mathematics problems, 881 lecture notes, a glossary of 390
terms and 97 badges, all in both Turkish and English.

## Download

1. Download `Odyssey-1.2.0-setup.exe` below.
2. Run it. Odyssey installs for your own user account — no administrator
   rights needed — and puts a shortcut in the Start menu and on your desktop.

Windows may show "Windows protected your PC" the first time, because the
installer is not code-signed yet. Click **More info**, then **Run anyway**.

If Odyssey 1.1.0 is already installed, it offers this update on its own and
downloads only the files that changed (`Odyssey-1.2.0-patch-1.1.0.exe`)
instead of the full installer; your progress, notes and settings are kept.
Older versions download the full installer.

The Docker exercises need Docker Desktop, which you install separately;
the other paths need nothing extra.

# Odyssey 1.2.0 — Sistem Tasarımı: CI/CD ve DevOps

Yeni bir patika açılıyor: Sistem Tasarımı. İlk modülü CI/CD ve DevOps,
otomatik testlerden bir Python projesinin baştan sona GitHub Actions
hattına uzanıyor. İş akışı alıştırmalarında YAML dosyasını siz
yazıyorsunuz, Odyssey onu GitHub'ın kurallarına göre denetliyor; hiçbir
şey çalıştırılmıyor, hesap gerekmiyor.

## Eklendi
- **Sistem Tasarımı (CI/CD) patikası açıldı.** İlk modül **CI/CD ve
  DevOps** (17 bölüm): otomatik testler ve kalite kapıları, GitHub Actions
  iş akışının yapısı, tetikleyiciler, işler ve bağımlılıklar, matris,
  önbellek, artifact ve paketleme, gizli değerler, sürümleme ve etiketler,
  dağıtım stratejileri, konteynerle CI/CD, dal stratejisi ve PR
  kontrolleri, kararsız testler; sonunda bir Python projesinin baştan sona
  hattı. İkinci modül **MLOps ve ML Sistem Tasarımı** sonraki sürümlerde
  geliyor.
- Yeni rozetler, "Hefaistos" unvanı, sözlükte CI/CD terimleri, Veri
  Mühendisi ve ML Mühendisi rotalarında CI/CD adımı.

## Düzeltildi
- **Bilgisayar yeni açıldığında program daha hızlı açılıyor.** Program
  bir süredir kullanılmadıysa açılış animasyonu "Hazırlanıyor" yazısında
  15 saniyeyi aşan bir süre bekleyebiliyordu. Ders, not ve sürüm notu
  sayfalarını gösteren bileşen artık program açıldıktan sonra arka planda
  hazırlanıyor; pencere onu beklemiyor.
- **Sözlükte NLP ve Üretken Yapay Zekâ terimlerinin başlığı görünüyor.** Bu
  iki grubun başlığı yerine ham bir etiket yazıyordu.

## Sayılarla

On dört tamamlanmış patika ve Sistem Tasarımı'nın ilk modülü — 438 bölüm,
11453 sınav sorusu, 1935 alıştırma (85'i Git terminalinde), 300 matematik
problemi, 881 ders notu, 390 terimlik bir sözlük ve 97 rozet; tamamı
Türkçe ve İngilizce.

## İndirme

1. Aşağıdan `Odyssey-1.2.0-setup.exe` dosyasını indirin.
2. Çalıştırın. Odyssey kendi kullanıcı hesabınıza kuruluyor — yönetici
   yetkisi gerekmiyor — ve Başlat menüsüne ve masaüstüne kısayol koyuyor.

Windows ilk seferde "Windows kişisel bilgisayarınızı korudu" diyebilir,
çünkü kurulum dosyası henüz imzalı değil. **Ek bilgi**'ye, ardından **Yine
de çalıştır**'a tıklayın.

Odyssey 1.1.0 kuruluysa bu güncellemeyi kendisi öneriyor ve kurulum
dosyasının tamamı yerine yalnızca değişen dosyaları indiriyor
(`Odyssey-1.2.0-patch-1.1.0.exe`); ilerlemeniz, notlarınız ve ayarlarınız
korunuyor. Daha eski sürümler tam kurulum dosyasını indiriyor.

Docker alıştırmaları için ayrıca Docker Desktop kurmanız gerekiyor; öbür
patikalar ek bir şey istemiyor.
