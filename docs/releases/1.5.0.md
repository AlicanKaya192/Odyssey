# Odyssey 1.5.0 — Rust

This release adds a seventeenth path: Rust, from no code at all to a very
advanced level, with exercises that compile on the real Rust compiler.

## Added
- **Rust path.** Three modules from no code at all to a very advanced level:
  Rust Fundamentals (types, operators, input, ownership, error handling), Going
  Deeper in Rust (generics, traits, threads, serde, clap), Advanced Rust (unsafe,
  atomics, your own async executor, tokio, macros, FFI). Exercises compile with
  the real Rust compiler on your computer; the first section covers
  installation, and compile errors are explained. serde, clap and tokio come
  with the program, so no internet is needed; you can clear their cache in
  Settings › Storage.

## Download

1. Download `Odyssey-1.5.0-setup.exe` below.
2. Run it. Odyssey installs to your own user account — no administrator rights
   needed — and puts a shortcut in the Start menu and on the desktop.

Windows may say "Windows protected your PC" the first time, because the
installer is not signed yet. Click **More info**, then **Run anyway**.

If Odyssey 1.4.0 is installed, it offers this update itself and downloads only
the files that changed instead of the whole installer
(`Odyssey-1.5.0-patch-1.4.0.exe`); your progress, notes and settings are kept.
Older versions download the full installer.

The CS50 Python videos play from YouTube, so they need an internet connection;
everything else works offline. Docker exercises also need Docker Desktop and
Rust exercises need the Rust compiler; the other paths need nothing extra.

# Odyssey 1.5.0 — Rust

Bu sürüm on yedinci patikayı ekliyor: Rust. Hiç kod bilmeden başlayıp çok ileri
düzeye kadar gidiyor, alıştırmalar gerçek Rust derleyicisiyle derleniyor.

## Eklendi
- **Rust patikası.** Hiç kod bilmeden başlayıp çok ileri düzeye kadar üç
  modül: Rust Temelleri (türler, işleçler, girdi, sahiplik, hata yönetimi),
  Rust'ta Derinleşmek (generic, trait, iş parçacığı, serde, clap), İleri Rust
  (unsafe, atomikler, kendi async çalıştırıcınız, tokio, makrolar, FFI).
  Alıştırmalar bilgisayarınızdaki gerçek Rust derleyicisiyle derleniyor; ilk
  bölüm kurulumu anlatıyor, derleme hataları açıklanıyor. serde, clap ve tokio
  programla geliyor, internet gerekmiyor; önbelleği Ayarlar › Depolama'dan
  silebilirsiniz.

## İndirme

1. Aşağıdan `Odyssey-1.5.0-setup.exe` dosyasını indirin.
2. Çalıştırın. Odyssey kendi kullanıcı hesabınıza kuruluyor — yönetici
   yetkisi gerekmiyor — ve Başlat menüsüne ve masaüstüne kısayol koyuyor.

Windows ilk seferde "Windows kişisel bilgisayarınızı korudu" diyebilir,
çünkü kurulum dosyası henüz imzalı değil. **Ek bilgi**'ye, ardından **Yine
de çalıştır**'a tıklayın.

Odyssey 1.4.0 kuruluysa bu güncellemeyi kendisi öneriyor ve kurulum
dosyasının tamamı yerine yalnızca değişen dosyaları indiriyor
(`Odyssey-1.5.0-patch-1.4.0.exe`); ilerlemeniz, notlarınız ve ayarlarınız
korunuyor. Daha eski sürümler tam kurulum dosyasını indiriyor.

CS50 Python videoları YouTube'dan oynatıldığı için internet bağlantısı
istiyor; geri kalan her şey çevrimdışı çalışıyor. Docker alıştırmaları için
Docker Desktop, Rust alıştırmaları için Rust derleyicisi gerekiyor; öbür
patikalar ek bir şey istemiyor.
