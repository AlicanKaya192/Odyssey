# Odyssey 1.7.0 — macOS and Exercise Practice

This release brings an experimental macOS version for Apple Silicon Macs and
a new way to practise: five mixed exercises from the sections you finished.

## Added
- **macOS version (experimental).** Odyssey now also runs on Macs with
  Apple Silicon (M1 and later): open the `.dmg` from the release page and drag Odyssey into
  the Applications folder. The app is not signed by Apple, so the first
  time macOS will not open it; click "Open Anyway" once in System Settings ›
  Privacy & Security (the steps are in the README). SQL exercises, in-app
  updates, streak reminders and sounds are not available on the Mac yet.
  Every exercise except SQL and Docker passed an automatic check on a Mac;
  Docker exercises, step-by-step tracing and taking a quiz have not been
  tried on a Mac yet. If something goes wrong, please report it.
- **Exercise practice.** Once you finish at least three sections of a
  module, the review card at the top of the path gets a second button:
  five mixed exercises from the sections you finished, with hints closed.
  It uses Python code exercises and maths problems; the editor opens with
  the starter code, and your saved solutions and attempt history stay as
  they are. At the end you see which ones you solved, where you used help
  that shows the answer, and links back to the sections of the ones you
  did not solve.

## Changed
- **Some exercises were updated to give the same result on every
  computer.** In a few exercises the same solution printed a different last
  digit on Windows and on macOS. In Big Data the orders file is written with
  the same line endings everywhere (CSV sizes are slightly smaller); two
  exercises that compare file sizes ask for `lineterminator="\n"`. A few
  Random Forest and HDBSCAN exercises have new data or model settings, and
  words with equal scores now come in alphabetical order. Exercises you have
  already solved still count as solved.

## Fixed
- **Moving to another exercise while code ran saved the result in the
  wrong place.** If you pressed Run and opened the next exercise before
  the result came back, the result was saved to the new exercise and it
  showed as solved even though you had not solved it. The result now goes
  to the exercise you ran.

## Download

**Windows**

1. Download `Odyssey-1.7.0-setup.exe` below.
2. Run it. Odyssey installs to your own user account — no administrator rights
   needed — and puts a shortcut in the Start menu and on the desktop.

Windows may say "Windows protected your PC" the first time, because the
installer is not signed yet. Click **More info**, then **Run anyway**.

If Odyssey 1.6.0 is installed, it offers this update itself and downloads only
the files that changed instead of the whole installer
(`Odyssey-1.7.0-patch-1.6.0.exe`); your progress, notes and settings are kept.
Older versions download the full installer.

**macOS (experimental, Apple Silicon only)**

1. Download `Odyssey-1.7.0-macos-arm64.dmg` below, open it and drag Odyssey
   into the Applications folder.
2. The first time, macOS will not open it because the app is not signed by
   Apple. Close the warning with **Done**, open **System Settings › Privacy &
   Security**, click **Open Anyway** next to the line about Odyssey and
   confirm. You only do this once.

If macOS says the app "is damaged", run
`xattr -dr com.apple.quarantine /Applications/Odyssey.app` in Terminal once
and open it again. On the Mac, Odyssey tells you when a new version is out;
download the new `.dmg` from this page and drag it into Applications again.
Your progress stays in `~/Library/Application Support/Odyssey`.

The CS50 Python videos play from YouTube, so they need an internet connection;
everything else works offline. Docker exercises also need Docker Desktop and
Rust exercises need the Rust compiler; the other paths need nothing extra.

# Odyssey 1.7.0 — macOS ve Alıştırma Tekrarı

Bu sürüm Apple Silicon'lu Mac'ler için deneysel bir macOS sürümü ve yeni bir
çalışma biçimi getiriyor: bitirdiğiniz bölümlerden karışık beş alıştırma.

## Eklendi
- **macOS sürümü (deneysel).** Odyssey artık Apple Silicon'lu (M1 ve
  sonrası) Mac'lerde de çalışıyor: sürüm sayfasındaki `.dmg` dosyasını açıp Odyssey'i
  Uygulamalar klasörüne sürükleyin. Program Apple tarafından imzalanmadığı
  için ilk açılışta macOS onu açmaz; Sistem Ayarları › Gizlilik ve
  Güvenlik'te "Yine de Aç"a bir kez basmanız yeterli (adımlar README'de).
  Mac'te SQL alıştırmaları, uygulama içi güncelleme, seri hatırlatmaları ve
  sesler şimdilik yok. SQL ve Docker dışındaki bütün alıştırmalar Mac'te
  otomatik denetimden geçti; Docker alıştırmaları, adım adım izleme ve sınav
  çözme Mac'te henüz denenmedi. Bir sorunla karşılaşırsanız bildirmeniz çok
  işe yarar.
- **Alıştırma tekrarı.** Bir modülde en az üç bölüm bitirince yolun
  başındaki tekrar kartında ikinci bir düğme çıkıyor: bitirdiğiniz
  bölümlerden karışık beş alıştırma, ipuçları kapalı. Python kod
  alıştırmaları ve matematik problemleri geliyor; editör başlangıç koduyla
  açılıyor, kayıtlı çözümleriniz ve deneme geçmişiniz değişmiyor. Sonda
  hangilerini çözdüğünüz, hangisinde çözümü gösteren bir yardım
  kullandığınız ve çözemediklerinizin bölümüne giden bağlantılar.

## Değişti
- **Bazı alıştırmalar her bilgisayarda aynı sonucu verecek şekilde
  güncellendi.** Aynı çözüm Windows'ta ve macOS'ta birkaç alıştırmada son
  basamakta farklı sayı veriyordu. Büyük Veri'de sipariş dosyası her yerde
  aynı satır sonuyla yazılıyor (CSV boyutları biraz küçüldü); dosya boyutu
  karşılaştıran iki alıştırma `lineterminator="\n"` istiyor. Birkaç Random
  Forest ve HDBSCAN alıştırmasında veri ya da model ayarı değişti, eşit
  puanlı kelimeler artık abece sırasıyla geliyor. Daha önce çözdüğünüz
  alıştırmalar çözülmüş sayılmaya devam ediyor.

## Düzeltildi
- **Kod çalışırken başka alıştırmaya geçilince sonuç yanlış yere
  yazılıyordu.** Çalıştır'a basıp sonuç gelmeden sonraki alıştırmaya
  geçilirse sonuç yeni alıştırmaya kaydediliyor, o alıştırma hiç
  çözülmeden çözülmüş görünüyordu. Sonuç artık kodun çalıştırıldığı
  alıştırmaya kaydediliyor.

## İndirme

**Windows**

1. Aşağıdan `Odyssey-1.7.0-setup.exe` dosyasını indirin.
2. Çalıştırın. Odyssey kendi kullanıcı hesabınıza kuruluyor — yönetici
   yetkisi gerekmiyor — ve Başlat menüsüne ve masaüstüne kısayol koyuyor.

Windows ilk seferde "Windows kişisel bilgisayarınızı korudu" diyebilir,
çünkü kurulum dosyası henüz imzalı değil. **Ek bilgi**'ye, ardından **Yine
de çalıştır**'a tıklayın.

Odyssey 1.6.0 kuruluysa bu güncellemeyi kendisi öneriyor ve kurulum
dosyasının tamamı yerine yalnızca değişen dosyaları indiriyor
(`Odyssey-1.7.0-patch-1.6.0.exe`); ilerlemeniz, notlarınız ve ayarlarınız
korunuyor. Daha eski sürümler tam kurulum dosyasını indiriyor.

**macOS (deneysel, yalnızca Apple Silicon)**

1. Aşağıdan `Odyssey-1.7.0-macos-arm64.dmg` dosyasını indirin, açın ve
   Odyssey'i Uygulamalar klasörüne sürükleyin.
2. Program Apple tarafından imzalanmadığı için macOS ilk seferde onu açmaz.
   Uyarıyı **Bitti** ile kapatın, **Sistem Ayarları › Gizlilik ve
   Güvenlik**'i açın, Odyssey'in engellendiğini söyleyen satırın yanındaki
   **Yine de Aç**'a basıp onaylayın. Bunu bir kez yapmanız yeterli.

macOS uygulamanın "hasarlı" olduğunu söylerse Terminal'de bir kez
`xattr -dr com.apple.quarantine /Applications/Odyssey.app` çalıştırıp
yeniden açın. Mac'te Odyssey yeni sürüm çıkınca haber veriyor; yeni `.dmg`'yi
bu sayfadan indirip yine Uygulamalar'a sürüklemeniz gerekiyor. İlerlemeniz
`~/Library/Application Support/Odyssey` klasöründe kalıyor.

CS50 Python videoları YouTube'dan oynatıldığı için internet bağlantısı
istiyor; geri kalan her şey çevrimdışı çalışıyor. Docker alıştırmaları için
Docker Desktop, Rust alıştırmaları için Rust derleyicisi gerekiyor; öbür
patikalar ek bir şey istemiyor.
