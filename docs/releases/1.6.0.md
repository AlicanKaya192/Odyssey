# Odyssey 1.6.0 — Security, Statistics and the Command Line

This release adds three paths: Cyber Security with Python in four modules,
Statistics and A/B Testing in two, and the Command Line. Odyssey now has
twenty paths.

## Added
- **Cyber Security with Python path.** The security topics a computer
  science student meets over four years, in four modules and from the
  defender's side: Security Fundamentals (threat modelling, authentication,
  password storage), Cryptography (hashes, HMAC, cipher modes, RSA,
  Diffie-Hellman, signatures, TLS), Network and Web Security (firewalls,
  DNS, the OWASP Top 10:2025, SQL injection, XSS, CSRF, SSRF) and System Security
  and Operations (memory safety, secrets management, logging and intrusion
  detection, incident response, forensics, privacy, ethics and responsible
  disclosure). Everything is done in Python with small examples built inside
  your computer; no exercise goes on the network or touches a real system.
- **Statistics and A/B Testing path.** Two modules: Statistical Inference
  (samples, distributions, confidence intervals, hypothesis tests, power
  analysis) and Experiment Design and A/B Testing (setting up an experiment,
  reading the results, peeking, multiple comparisons, CUPED, network
  effects, making the decision). Every number is measured by simulation, so
  you see on your own data how a mistake misleads an experiment.
- **Command Line path.** The terminal, the file system, pipes, grep and
  find, permissions, environment variables, writing scripts and exit codes.
  The exercises run in a Linux terminal inside the program; nothing is
  installed on your computer and none of your files are touched.
  In the terminal the Tab key completes file, folder and command names, and
  in Git exercises subcommands and branch names too.
- **Text size.** In Settings › Appearance you can show lessons, notes, the
  code editor and the terminal at 90%, 100%, 115% or 130%; open screens
  change right away.

## Download

1. Download `Odyssey-1.6.0-setup.exe` below.
2. Run it. Odyssey installs to your own user account — no administrator rights
   needed — and puts a shortcut in the Start menu and on the desktop.

Windows may say "Windows protected your PC" the first time, because the
installer is not signed yet. Click **More info**, then **Run anyway**.

If Odyssey 1.5.0 is installed, it offers this update itself and downloads only
the files that changed instead of the whole installer
(`Odyssey-1.6.0-patch-1.5.0.exe`); your progress, notes and settings are kept.
Older versions download the full installer.

The CS50 Python videos play from YouTube, so they need an internet connection;
everything else works offline. Docker exercises also need Docker Desktop and
Rust exercises need the Rust compiler; the other paths need nothing extra.

# Odyssey 1.6.0 — Güvenlik, İstatistik ve Komut Satırı

Bu sürüm üç patika ekliyor: dört modüllü Python ile Siber Güvenlik, iki
modüllü İstatistik ve A/B Testi ve Komut Satırı. Odyssey'de artık yirmi
patika var.

## Eklendi
- **Python ile Siber Güvenlik patikası.** Bir bilgisayar mühendisliği
  öğrencisinin dört yılda gördüğü güvenlik konuları, dört modülde ve
  savunma tarafından: Güvenlik Temelleri (tehdit modeli, kimlik doğrulama,
  parola saklama), Kriptografi (özet, HMAC, şifreleme kipleri, RSA,
  Diffie-Hellman, imza, TLS), Ağ ve Web Güvenliği (güvenlik duvarı, DNS,
  OWASP Top 10:2025, SQL enjeksiyonu, XSS, CSRF, SSRF) ve Sistem Güvenliği ve
  Operasyon (bellek güvenliği, sır yönetimi, kayıt ve saldırı tespiti, olay
  müdahalesi, adli bilişim, gizlilik, etik ve sorumlu açıklama). Her şey
  Python'la, bilgisayarınızın içinde kurulan küçük örneklerle; hiçbir
  alıştırma ağa çıkmaz ya da gerçek bir sisteme dokunmaz.
- **İstatistik ve A/B Testi patikası.** İki modül: İstatistiksel Çıkarım
  (örneklem, dağılımlar, güven aralığı, hipotez testleri, güç analizi) ve
  Deney Tasarımı ve A/B Testi (deneyi kurmak, sonuçları okumak, sıralı
  bakma, çoklu karşılaştırma, CUPED, ağ etkisi, karar vermek). Sayıların
  hepsi benzetimle ölçülüyor; bir hatanın deneyi nasıl yanılttığını kendi
  verinizde görüyorsunuz.
- **Komut Satırı patikası.** Terminal, dosya sistemi, borular, grep ve
  find, izinler, ortam değişkenleri, betik yazmak ve çıkış kodları.
  Alıştırmalar programın içindeki bir Linux terminalinde yapılıyor;
  bilgisayarınıza hiçbir şey kurulmuyor, hiçbir dosyanıza dokunulmuyor.
  Terminalde Tab tuşu dosya, klasör ve komut adlarını tamamlıyor; Git
  alıştırmalarında alt komutları ve dal adlarını da.
- **Yazı boyu.** Ayarlar › Görünüm'den dersleri, notları, kod editörünü ve
  terminali %90, %100, %115 ya da %130 boyunda okuyabilirsiniz; değişiklik
  açık ekranlara hemen uygulanır.

## İndirme

1. Aşağıdan `Odyssey-1.6.0-setup.exe` dosyasını indirin.
2. Çalıştırın. Odyssey kendi kullanıcı hesabınıza kuruluyor — yönetici
   yetkisi gerekmiyor — ve Başlat menüsüne ve masaüstüne kısayol koyuyor.

Windows ilk seferde "Windows kişisel bilgisayarınızı korudu" diyebilir,
çünkü kurulum dosyası henüz imzalı değil. **Ek bilgi**'ye, ardından **Yine
de çalıştır**'a tıklayın.

Odyssey 1.5.0 kuruluysa bu güncellemeyi kendisi öneriyor ve kurulum
dosyasının tamamı yerine yalnızca değişen dosyaları indiriyor
(`Odyssey-1.6.0-patch-1.5.0.exe`); ilerlemeniz, notlarınız ve ayarlarınız
korunuyor. Daha eski sürümler tam kurulum dosyasını indiriyor.

CS50 Python videoları YouTube'dan oynatıldığı için internet bağlantısı
istiyor; geri kalan her şey çevrimdışı çalışıyor. Docker alıştırmaları için
Docker Desktop, Rust alıştırmaları için Rust derleyicisi gerekiyor; öbür
patikalar ek bir şey istemiyor.
